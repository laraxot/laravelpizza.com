| Version | Supported          |
| ------- | ------------------ |

## Reporting a Vulnerability

Do **not** open a public GitHub issue for security problems.

Email **marco.sottana@gmail.com** with:

- a short description of the issue
- steps to reproduce (if safe)
- impact assessment (what an attacker could do)
- your preferred disclosure timeline

We aim to acknowledge reports within **72 hours** and to share a remediation
plan or fix status within **14 days** when feasible.

Please give us reasonable time to patch before public disclosure.
