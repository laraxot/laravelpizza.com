# Confine UI

Pattern condivisi per loghi partner, disclosure e CTA devono rispettare
contrasto, focus, reflow, text spacing e alt text. Niente componenti «ad slot»
o caroselli forzati.

## Post-GO

- Componenti sobri tipizzati (logo + nome + link opzionale).
- Stati disabled/assenti senza layout rotto.
- Preferire lista accessibile a griglia banner.
