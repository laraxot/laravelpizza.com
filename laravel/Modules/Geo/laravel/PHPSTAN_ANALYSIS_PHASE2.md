**Evidence**:
```

```

**Why it's wrong**: These traits ARE used; grep confirms they're imported and applied across modules.

**Resolution options**:

2. ❌ Add @phpstan-ignore per trait (user forbids this pattern)
3. ❌ Delete traits (breaks code)

**Recommended action**: User adds rule to phpstan.neon:
