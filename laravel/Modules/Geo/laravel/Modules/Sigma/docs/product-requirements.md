## 1. Panoramica del Prodotto

### Descrizione Breve
Il modulo Sigma è un sistema di **gestione documentale** per la Pubblica Amministrazione conforme agli standard di protocollazione e archiviazione.

### Visione
Gestione documentale completa con:
- Protocollo informatico
- Fascicolazione
- Archiviazione sostitutiva
- Gestione workflow

### Target Users
- **Uffici**: Protocollo
- **Dirigenti**: Firmas
- **Archivio**: Conservazione

---

## 2. Problema

### Problema Risolto
- Documenti cartacei
- Protocollo manuale
- Difficoltà ricerca
- Conservazione non conforme
