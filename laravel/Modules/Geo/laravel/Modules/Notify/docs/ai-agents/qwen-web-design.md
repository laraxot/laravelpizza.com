## Accessibilità WCAG 2.2

**European Accessibility Act** - In vigore dal 28 Giugno 2025:
- Sanzioni fino a €50.000
- Obbligatorio per prodotti/servizi digitali

### 4 Principi POUR

1. **Percepibile** - Alt text, contrasto
2. **Utilizzabile** - Navigazione tastiera
3. **Comprensibile** - Linguaggio chiaro
4. **Robust** - HTML semantico

---

## Web Design Cinetico

**Movimento come elemento centrale**:
- **Animazioni CSS** - Hover effects, transitions
- **JavaScript (GSAP)** - Timeline animations
- **Animazioni SVG** - Icone, indicatori
- **WebGL/Three.js** - Visualizzazioni 3D

### Best Practices

- ✅ Utilità - Ogni animazione ha funzione comunicativa
- ✅ Performance - Accelerate CSS/GPU
- ✅ Coerenza - Timing uniformi
- ✅ Accessibilità - Rispetta prefers-reduced-motion

---

## Micro-Interazioni

6 tipi principali:

1. **Hover Effects** - Pulsanti cambiano colore
2. **Form Feedback** - Validazione inline
3. **Transizioni** - Cambiamenti di stato fluidi
4. **Loading States** - Spinner, skeleton
5. **Counters** - Aggiornamenti tempo reale
6. **Scroll Effects** - Rivelazione progressiva

## Design Emozionale

**Psicologia applicata al trading**:
- First Impression Bias

- Flow State
- Reciprocità - Badge, punti
- Social Proof
- Storytelling Visivo

## Mobile First

**Requisiti**:
- Touch target ≥ 44x44px
- Font size ≥ 16px
- Spaziatura adeguata
- Hamburger menu
- CTA sticky
- Loading ottimizzati
