# Analisi PHPStan livello 10 - tema

## Scopo
Descrivere un controllo minimo per PHPStan sul tema, con note per ambito e limiti dell'analisi.

## Quando usare
- Prima di rilasci o merge importanti.
- Dopo modifiche a file PHP nel tema o nelle sue dipendenze.

## Esito (da aggiornare a ogni verifica)
- **Ambito**: core del tema
- **Stato**: da verificare
- **Errori correnti**: da aggiornare

## Note
Se il tema contiene solo documentazione o asset statici, indicare esplicitamente che non ci sono file PHP da analizzare.
