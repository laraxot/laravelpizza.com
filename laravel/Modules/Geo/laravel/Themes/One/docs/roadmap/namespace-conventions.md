# Namespace e convenzioni tema

## Obiettivo

Allineare namespace, percorsi e naming conventions per ridurre ambiguita e duplicazioni.

## Passi operativi

1. Inventariare i namespace usati nel tema.
2. Identificare i casi non conformi.
3. Definire naming conventions per risorse e componenti.
4. Aggiornare i riferimenti nelle doc.
5. Validare con controlli automatici.

## Criticita

- File legacy con naming non standard.
- Riferimenti incrociati non aggiornati.

## Punti di forza

- Regole gia presenti in documentazione.
- Struttura tema semplice.

## Punti di debolezza

- Mancanza di indice unico dei namespace.
- Convenzioni non applicate in modo uniforme.

## Colli di bottiglia

- Allineamento tra file system e namespace.
- Aggiornamento dei riferimenti nei template.

## Come risolverli

- Definire una tabella di mapping namespace.
- Eseguire correzioni progressive per cartella.

## Religione

- Naming coerente per evitare sorprese.

## Filosofia

- Namespace chiaro = manutenzione piu semplice.

## Politica

- Ogni nuovo file deve rispettare le convenzioni.

## Output attesi

- Namespace coerenti e documentati.
- Riduzione di conflitti e duplicazioni.
