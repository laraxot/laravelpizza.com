## Overview

This guide describes how the Zero theme integrates JpGraph-generated chart images into PDF reports. The theme provides PDF templates, Blade components, and print-optimized CSS for professional chart presentation.

### Workflow

```
LimeSurvey Data
    ↓
healthcare_app Module (Chart Generation)
    ↓
JpGraph Actions (PNG Generation)
    ↓
Zero Theme (PDF Templates)
    ↓
Html2Pdf / Spatie PDF
    ↓
PDF Download
```

### Key Principles

1. **Theme Does NOT Generate Charts**: Charts are generated by healthcare_app/Chart modules using JpGraph Actions
2. **Theme Provides Layout**: PDF templates, Blade components, and styling
3. **Separation of Concerns**: Business logic (healthcare_app) vs Presentation (Zero Theme)

---

## Theme Responsibilities

### What the Theme DOES

✅ **PDF Templates**: Blade templates for PDF layout  
✅ **Chart Containers**: Blade components for chart embedding  
✅ **Print CSS**: Optimized styles for PDF output  
✅ **Layout Management**: Page breaks, margins, headers/footers  
✅ **Visual Consistency**: Styling for professional appearance

### What the Theme DOES NOT

❌ **Chart Generation**: That's healthcare_app/Chart modules  
❌ **JpGraph Actions**: That's Chart module  
❌ **Data Querying**: That's healthcare_app/Limesurvey modules  
❌ **Business Logic**: That's healthcare_app module

## Chart Image Embedding

### Basic Chart Container

```blade
{{-- Themes/Zero/resources/views/pdf/components/chart-container.blade.php --}}
<div class="chart-container" style="page-break-inside: avoid; margin: 20px 0;">
    @if(isset($chartTitle))
        <h3 style="font-size: {{ $pdf->font_size_question ?? 14 }}pt; 
                   margin-bottom: 10px; 
                   color: {{ $pdf->color ?? '#000000' }};">
            {{ $chartTitle }}
        </h3>
    @endif
    
    @if(isset($chartImage) && file_exists(public_path($chartImage)))
        <img src="{{ public_path($chartImage) }}" 
             alt="{{ $chartTitle ?? 'Chart' }}" 
             style="width: 100%; 
                    height: auto; 
                    max-width: 100%; 
                    display: block;">
    @else
        <div class="chart-placeholder" style="padding: 40px; text-align: center; color: #999;">
            Chart not available
        </div>
    @endif
    
    @if(isset($chartFooter))
        <p style="font-size: {{ ($pdf->font_size ?? 10) - 2 }}pt; 
                  margin-top: 10px; 
                  color: #666; 
                  text-align: center;">
            {{ $chartFooter }}
        </p>
    @endif
</div>
```

### Chart Grid (Multiple Charts)

{{-- Themes/Zero/resources/views/pdf/components/chart-grid.blade.php --}}

## Print CSS Optimization

### Page Break Management

```css
/* Avoid page breaks inside chart containers */
.chart-container {
    page-break-inside: avoid;
    page-break-after: auto;
}

/* Force page break before major sections */
.chart-section {
    page-break-before: always;
}

/* Avoid orphans/widows */
.chart-container h3 {
    page-break-after: avoid;
}
```

### Image Optimization

```css
/* Ensure images fit page width */
.chart-container img {
    max-width: 100%;
    height: auto;
    display: block;
    margin: 0 auto;
}

/* Prevent image overflow */
.chart-container {
    overflow: hidden;
}
```

### Typography for Print

```css
/* Optimize font sizes for print */
.chart-title {
    font-size: 14pt;
    font-weight: bold;
    margin-bottom: 8pt;
}

.chart-footer {
    font-size: 9pt;
    color: #666;
    margin-top: 6pt;
}
```

## Best Practices

### 1. Chart Image Paths

```php
/**
 * Pattern corretto per path chart images.
 * 
 * JpGraph genera PNG in public_path('chart/')
 * Zero Theme usa path relativo per embedding
 */
$chartImage = 'chart/monthly-123.png';  // Path relativo
$fullPath = public_path($chartImage);   // Path completo per verifica

// In Blade template
@if(file_exists(public_path($chartImage)))
    <img src="{{ public_path($chartImage) }}" ...>
@endif
```

### 2. Page Break Strategy

```blade
{{-- Strategia page break per PDF professionali --}}
<div style="page-break-inside: avoid;">
    {{-- Chart container --}}
    @include('zero::pdf.components.chart-container', [...])
</div>

{{-- Force new page after section --}}
<div style="page-break-before: always;">
    {{-- New section --}}
</div>
```

### 3. Chart Sizing

```php
/**
 * Dimensioni ottimali per PDF A4.
 * 
 * Landscape: 800x400px (ottimo per bar/line)
 * Portrait: 600x300px (ottimo per pie)
 */
$chartData = ChartData::from([
    'width' => 800,   // Landscape A4
    'height' => 400,
]);
```

### 4. Error Handling

```blade
{{-- Gestione errori chart mancanti --}}
@if(isset($chartImage) && file_exists(public_path($chartImage)))
    <img src="{{ public_path($chartImage) }}" ...>
@else
    <div class="chart-placeholder">
        Chart generation in progress...
    </div>
@endif
```

### 5. Performance Optimization

```php
/**
 * Pattern caching per chart images.
 */
$cacheKey = 'chart-'.$questionChart->id.'-'.md5(serialize($filter));
$chartImage = Cache::tags(['charts'])
    ->remember($cacheKey, 3600, function () use ($questionChart) {
        return $this->generateChart($questionChart);
    });
```

## Integration with healthcare_app Module

### PDF Generation Action

```php
/**
 * Pattern completo: healthcare_app → JpGraph → Zero Theme → PDF
 */
class MakePdf2Action
{
    public function execute(SurveyPdf $surveyPdf, AnswersFilterData $filter): BinaryFileResponse
    {
        // 1. Genera chart images (JpGraph)
        $questionCharts = $surveyPdf->questionCharts->where('show_on_pdf', 1);
        foreach ($questionCharts as $questionChart) {
            $chartImage = app(MakeMonthlyChartForPdfAction::class)
                ->execute($questionChart, $filter);
            $questionChart->img_src = $chartImage;
        }
        
        // 2. Render Blade template (Zero Theme)
        $html = view('zero::pdf.reports.survey-monthly', [
            'surveyPdf' => $surveyPdf,
            'questionCharts' => $questionCharts,
            'pdf' => $surveyPdf->pdfStyle,
        ])->render();
        
        // 3. Convert to PDF (Html2Pdf)
        $html2pdf = new Html2Pdf('L', 'A4', 'it');
        $html2pdf->writeHTML($html);
        
        $filename = Str::slug($surveyPdf->name).'.pdf';
        $path = storage_path('app/survey_reports/'.$filename);
        $html2pdf->output($path, 'F');
        
        return response()->download($path);
    }
}
```
