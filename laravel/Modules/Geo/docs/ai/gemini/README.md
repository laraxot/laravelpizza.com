## Panoramica

Gemini Code Assist è l'estensione AI di Google per IDE che integra Gemini AI direttamente nell'ambiente di sviluppo. Questa guida descrive come configurare e utilizzare Gemini Code Assist al meglio per lo sviluppo del progetto PTVX.

## Caratteristiche Principali

- **Integrazione IDE**: VS Code e IntelliJ supportati
- **Agent Mode**: Pair programmer per task complessi
- **Code Customization**: Suggerimenti basati su codebase privato (Enterprise)
- **Context Drawer**: Gestione contesto file e cartelle
- **Custom Commands**: Shortcut per task ripetitivi

---

## Quick Start

1. **Installa Gemini Code Assist**: [VS Code Extension](https://marketplace.visualstudio.com/items?itemName=GoogleCloudTools.cloud-code) o [IntelliJ Plugin](https://plugins.jetbrains.com/plugin/22324-google-cloud-code)
2. **Configura MCP**: Vedi [Setup MCP](./mcp-setup.md)
3. **Apri progetto**: Apri la cartella `laravel/` come workspace
4. **Inizia a sviluppare**: Usa la chat per interagire con Gemini
