# regola: stack frontoffice (modulo Geo)

## mantra

**Tailwind CSS v4 + Alpine.js v3 + Lit v3 + DaisyUI v5 + Flowbite + Filament v5 + Vite**

Geo contribuisce **Lit** (`map-lit`, `coordinate-picker-lit`). Non introdurre Bootstrap JS né React FO.
