# Product Strategy: PTVX Ecosystem

## 🌍 Market Context
Growing demand for digital transformation in Italian Public Administration (PA), requiring specialized but interoperable HR and Performance tools.

## ⚔️ Competitive Landscape
- **Legacy Monoliths:** High maintenance, slow updates.
- **Generic ERPs:** Lack specialized PA logic (Indennita, Legge 104, etc.).

## 💎 Unique Value Proposition
"Contract-First" modularity where each module is an independent micro-application sharing a standardized infrastructure (Xot).

## 🏛️ Strategic Pillars
1. **Agnostic Core:** Xot provides infrastructure without domain logic.
2. **Action-Oriented:** Logic resides in Actions, never Services.
3. **AI-Orchestrated:** Designed for AI agents to maintain and extend.

## 👥 Target Personas
- **PA Developer:** Needs to implement complex laws quickly.
- **PA Manager:** Needs reliable, auditable performance data.

## 🗺️ Strategic Roadmap (1-2 Years)
Transition from a Modular Monolith to a fully distributed Microservices architecture where modules can run on different clusters.
