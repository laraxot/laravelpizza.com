# User Research: PTVX Modular Framework

## 🔬 Research Goals
Understand the pain points of developers when creating new modules and the needs of PA managers for data consistency.

## 👥 Participants
| Name | Role | Date | Focus |
| :--- | :--- | :--- | :--- |
| Dev A | Backend Dev | Mar 2026 | DX, Scaffolding |
| Manager B | HR Manager | Mar 2026 | Data Reporting |

## 💡 Key Findings
- Developers find manual translation management tedious.
- Managers need a unified view of employee performance across multiple modules.

## 💬 Notable Quotes
> "If I have to copy-paste another Service Provider, I'm going to lose it." — *Dev A*

## ✅ Actionable Insights / Next Steps
- Automate translation discovery (implemented in `Lang` module).
- Create a cross-module "Dashboard" widget in `Xot`.
