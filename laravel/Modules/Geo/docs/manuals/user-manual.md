# Manuale utente Geo

Integra il [manuale actor-oriented](../manuale-uso-attori.md). Geo espone dati geografici e proxy OSM/Nominatim.

## Attori e uso

| Attore | Uso verificato |
|---|---|
| Utente/utente di gruppo | Usa mappe e geocoding attraverso gli endpoint del dominio. |
| Operatore/admin | Gestisce luoghi e località con i permessi specifici. |
| Super-admin | Bypassa le policy Geo secondo il contratto User. |

Il browser non deve chiamare direttamente OSM.
