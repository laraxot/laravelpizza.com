# Geo — BMAD dossier
## Product brief / PRD
Capture reliable location while supporting citizens who deny location permission or need manual entry.
## Architecture / UX / security
Geo Actions normalize coordinates/addresses and feed Fixcity/Mobile; public precision is policy-controlled.
## Epics and stories
Capture; provider fallback; map privacy/attribution.
## Gaps / release
Timeout/rate-limit fallback, precision policy, validation and provider attribution need candidate evidence.
