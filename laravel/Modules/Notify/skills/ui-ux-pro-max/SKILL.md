# UI/UX Pro Max Skill

## 🎯 Panoramica

Skill completa per UI/UX design di livello professionale per agenti AI. Fornisce linee guida, pattern e best practices per creare interfacce utente bellissime, accessibili e performanti.

## 📦 Installazione

### Metodo 1: NPM (Consigliato)

```bash
npx skills add nextlevelbuilder/ui-ux-pro-max-skill
```

### Metodo 2: Git Clone

```bash
cd /var/www/_bases/base_fixcity_fila5
git clone https://github.com/nextlevelbuilder/ui-ux-pro-max-skill.git skills/ui-ux-pro-max
```

### Metodo 3: Manuale

1. Crea directory `skills/ui-ux-pro-max`
2. Copia questo file in `skills/ui-ux-pro-max/SKILL.md`
3. Aggiungi a `.qwen/skills` o `.claude/skills`

## ✅ Best Practices

### 1. Accessibility First
- Always meet WCAG 2.1 AA minimum
- Use semantic HTML
- Provide alt text for images
- Ensure keyboard navigation
- Test with screen readers

### 2. Performance Optimization
- Minimize CSS/JS bundle size
- Use lazy loading for images
- Optimize for Core Web Vitals
- Implement code splitting
- Use CDN for assets

### 3. Responsive Design
- Mobile-first approach
- Test on multiple devices
- Use flexible layouts
- Optimize touch targets
- Consider fold placement

### 4. Design Consistency
- Use design tokens
- Maintain spacing scale
- Consistent color usage
- Typography hierarchy
- Component library

### 5. User-Centered Design
- Understand user needs
- Test with real users
- Iterate based on feedback
- Measure success metrics
- Continuous improvement
