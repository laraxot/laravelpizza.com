# Story 4.24: Nomi file .md agnostici

## Fase BMAD
Build + Measure (esecuzione + verifica). Nessun codice applicativo toccato: solo documentazione.

## Contesto
I moduli (`laravel/Modules/*`) sono riusati in piu' progetti. Un nome file che cita un progetto
specifico (`fixcity`) rende il modulo non agnostico: qui il progetto e' `base_ptvx_fila5` (ptvx).

## Regola
Nessun file `.md` del repository puo' contenere il nome di un progetto nel filename.

Mappatura applicata (deterministica, in ordine):

| Pattern | Sostituzione | Esempio |
|---|---|---|
| `^<progetto>-` | rimosso | `fixcity-competitor-census.md` → `competitor-census.md` |
| `[-_]of[-_]<progetto>` | rimosso | `ZEN_OF_FIXCITY.md` → `ZEN.md` |
| `<PROGETTO>_` | `APP_` | `FIXCITY_IMPROVEMENT_PROGRESS_1.md` → `APP_IMPROVEMENT_PROGRESS_1.md` |
| `<progetto>-` / `-<progetto>` | `app-` / `-app` | `zen-of-fixcity.md` → `zen.md` |

Collisione con file gia' esistente: se il contenuto e' identico dopo normalizzazione
(`sed 's/<progetto>/app/gI'`) il sorgente si elimina, altrimenti si segnala e si decide a mano.

## Esecuzione (2026-08-26)
- 5 rename (`git mv`): `Notify/docs/ZEN.md`, `_da-riconciliare/{ZEN,zen}[.DIVERGENZA].md`
- 1 eliminazione duplicato: `Notify/docs/reports/FIXCITY_IMPROVEMENT_PROGRESS_1.md`
  (near-duplicate di `APP_IMPROVEMENT_PROGRESS_1.md`: 42 righe di diff, tutte nomi/URL di progetto)
- 2 file con link aggiornati: `_da-riconciliare/ZEN.DIVERGENZA.md`,
  `Xot/docs/wiki/concepts/laraxot-religion-phpstan-fixes.md`
- Il resto del set (24 file, censiti a inizio sessione) risultava gia' rinominato da sessioni precedenti.

## Verifica reale
```bash
find . -type f -iname '*fixcity*' -name '*.md' \
  -not -path '*/node_modules/*' -not -path '*/vendor/*' -not -path '*/.git/*' | wc -l   # 0
grep -rl --include='*.md' -e 'ZEN_OF_FIXCITY' -e 'zen-of-fixcity' . | wc -l              # 0
```
