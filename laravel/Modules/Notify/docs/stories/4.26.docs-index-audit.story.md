# Story 4.26: Audit e riorganizzazione docs/index.md

## Fase BMAD
Build + Measure (esecuzione + verifica). Task docs-only: nessun file `.php` toccato,
nessun file fuori da `docs/`.

## Contesto
Notify e' il modulo con piu' documentazione del monorepo: 5100+ file `.md` sotto
`docs/` (1715 solo nella radice, oltre a 68 sottocartelle). Il vecchio `docs/index.md`
era il risultato di risoluzioni di conflitti git fatte male: sezioni duplicate alla
lettera ("Note sulla Manutenzione" ripetuta 6 volte), link a file non piu' esistenti.

## Esecuzione
- Audit completo di `docs/` (find/ls): 69 sottocartelle di primo livello + 1715 file
  `.md` in radice, censiti e raggruppati.
- Riscritto interamente `docs/index.md` come indice per argomento: 28 sottocartelle
  con proprio README/index linkate direttamente, 2 grandi (`ai-agents/` 311 file,
  `reports/` 35 file) senza indice locale segnalate con struttura interna, 35
  sottocartelle piccole (<=20 file) elencate per intero.
- I 1715 file di root sono stati raggruppati per argomento normalizzato
  (case/underscore/suffisso numerico ignorati): 805 argomenti distinti, organizzati
  in 19 categorie tematiche (naming conventions, roadmap, completamento, analisi,
  bugfix, testing, architettura, AI agent, email/notifiche, git, BMAD, refactoring,
  traduzioni, Filament, regole, sessioni, integrazioni, documentazione generale,
  altro). Un solo link canonico per argomento; le altre 910 varianti duplicate sono
  elencate in "Storico / da consolidare" (non cancellate, solo segnalate).
- Nessun file `.md` esistente cancellato, rinominato o modificato nel contenuto.

## Verifica reale
```bash
wc -l Modules/Notify/docs/index.md   # 2151 righe, ~88 KB
git status --short -- docs/          # solo docs/index.md + nuova story
```

## Debito residuo (fuori scope)
`ai-agents/` (311 file) e `reports/` (35 file) restano senza un indice locale
proprio: da creare in un task dedicato futuro.
