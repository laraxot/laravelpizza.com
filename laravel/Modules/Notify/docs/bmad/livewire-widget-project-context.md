# Context Notify

Le campanelle del panel sono Filament Notifications (vendor). Notify le monta e le configura (trigger custom `notify::livewire.database-notifications-trigger`, polling 60s, gate `XotData::disable_database_notifications`); non le riscrive come widget proprio.
