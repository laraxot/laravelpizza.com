# Headroom - Modulo Notify

Usare la configurazione Headroom comune del progetto quando si lavora su Notify.

## Comandi

```bash
headroom mcp status
headroom doctor
headroom savings
headroom perf --hours 24
```

- Config canonica: `../../../../../.headroom.yaml`.
