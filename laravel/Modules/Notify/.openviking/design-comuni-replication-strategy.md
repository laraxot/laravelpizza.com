## 🎯 GOAL

Replicate Design Comuni using **Tailwind @apply**, **NOT Bootstrap Italia CSS**.

---

## ✅ APPROACH

### HTML
- Use Bootstrap Italia class names
- `.it-header-wrapper`
- `.it-footer`
- `.hero-section`

### CSS
- Use Tailwind @apply
- `.it-header-wrapper { @apply text-white; }`
- NO Bootstrap Italia imports

---

## 🧘 MANTRAS

> *"Bootstrap Italia classes in HTML."*

> *"Tailwind @apply in CSS."*

> *"NO Bootstrap CSS imports."*
