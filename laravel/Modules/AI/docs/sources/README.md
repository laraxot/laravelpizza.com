# AI External Sources

Use this directory only for imported external material that should feed the AI wiki but should not live next to canonical module guidance files.

Examples:

- clipped articles;
- exported markdown from vendor docs;
- copied transcripts;
- summarized PDFs converted to markdown.

Do not place compiled wiki pages here.
