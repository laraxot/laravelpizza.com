# Story 3.3 — PHPStan AI Module: 9 Errors

## Problem

PHPStan analysis on Modules/AI reports 9 errors.

## Error Details

```
tests/Unit/Actions/ContextCompressorActionTest.php
  58  Call to undefined method Pest\PendingCalls\TestCall::assertLessThanOrEqual()
  59  Call to undefined method Pest\PendingCalls\TestCall::assertStringStartsWith()
  60  Call to undefined method Pest\PendingCalls\TestCall::assertMatchesRegularExpression()
  68  Call to undefined method Pest\PendingCalls\TestCall::assertSame()
```

## Root Cause

Test file uses `assert*()` methods directly on Pest pending call instead of using `expect()` pattern.

## Solution

Replace direct `assert*()` calls with proper Pest `expect()` assertions:

```php
// WRONG
test('compresses context', function (): void {
    $result->assertLessThanOrEqual();
});

// CORRECT
test('compresses context', function (): void {
    expect($result)->toBeLessThanOrEqual();
});
```
