# Extract Domain Handlers from AiAssistant into AI Module

## Objective

Eliminate duplication between AI and AiAssistant modules by extracting domain-specific handler implementations from AiAssistant into AI module's `Domain/` layer. Make AiAssistant a thin consumer of AI's abstraction rather than a parallel LLM orchestrator.

## Context

**Current State:**
- AI module: infra-only (LLM bridge, handler registry, completion abstraction)
- AiAssistant: parallel implementation of LLM orchestration, direct API calls to OpenAI/Groq
- **Duplication:** Both implement retry logic, response parsing, domain-specific completions
- **Tight Coupling:** AiAssistant imports OpenAI/Groq directly, bypassing AI's abstraction

**Problem Statement:**
- LLM logic scattered across two modules
- Adding new domain (HR, Production) requires reimplementing extraction patterns
- Changes to LLM integration require updates in multiple places
- AiAssistant is bloated with infra logic that should be in AI

**Solution:**
1. Create handler implementations in AI for each domain (Quotation, Intervention, Speech)
2. Refactor AiAssistant to call AI handlers instead of direct LLM
3. Remove direct LLM provider dependencies from AiAssistant

## Deliverables

### 1. Handler Classes in AI (Phase 1)

Create in `Modules/AI/app/Domain/`:

**`QuotationDraftHandler`**
- **Responsibility:** Extract quotation structure from scanned PDF or document
- **Input:** PDF bytes or base64, tenant context
- **Output:** `QuotationDraftExtractorInterface` result (items, customer, amount)
- **Implementation:** Move logic from `AiAssistant::OpenAiQuotationDraftExtractor`
- **Tests:** Mock LLM response, verify structured output, test error handling

**`InterventionReportHandler`**
- **Responsibility:** Generate intervention report from work description
- **Input:** work minutes, materials used, customer notes
- **Output:** `InterventionReportExtractorContract` result (summary, recommendations)
- **Implementation:** Move logic from `AiAssistant::OpenAiInterventionReportExtractor`
- **Tests:** Verify report structure, test with edge cases (no notes, max length)

**`QuotationModificationHandler`**
- **Responsibility:** Suggest quotation modifications based on change request
- **Input:** original quotation, customer request
- **Output:** `QuotationModificationExtractorInterface` result (line changes, new price)
- **Implementation:** Move logic from `AiAssistant::OpenAiQuotationModificationExtractor`
- **Tests:** Test modification parsing, price calculation validation

**`SpeechTranscriptionHandler`**
- **Responsibility:** Transcribe audio to text via OpenAI Whisper or Groq
- **Input:** audio bytes or URL
- **Output:** transcription text with confidence scores
- **Implementation:** Move logic from `AiAssistant::OpenAiWhisperTranscriptionProvider` + `GroqWhisperTranscriptionProvider`
- **Tests:** Mock API responses, test error recovery (timeout, API down)

### 2. Handler Registration (Phase 1)

Update `Modules/AI/app/Providers/AIServiceProvider.php`:

```php
public function register(): void {
    parent::register();
    
    app(AiActionHandlerRegistry::class)->register(
        'quotation-draft',
        QuotationDraftHandler::class
    );
    app(AiActionHandlerRegistry::class)->register(
        'intervention-report',

    );
}
```

## Related Issues & Decisions

**Design Decision:** Handlers are services, not Actions
- **Rationale:** Handlers are stateless request→response, not queueable
- **Alternative:** Could be Actions with `execute()`, but overhead for synchronous requests
- **Decision:** Implement `AiActionHandlerContract` interface instead

**Design Decision:** Consolidation is not merge
- **Rationale:** AI stays infra; AiAssistant stays domain
- **Alternative:** Merge modules into single AI module
- **Decision:** Extract handlers only; AiAssistant refactors to call them (Phase 2)

## Risks & Mitigations

| Risk | Mitigation |
|------|-----------|
| LLM API changes during dev | Mock all responses in tests; use recorded cassettes |
| Handler interface instability | Lock `AiActionHandlerContract` with version; document breaking changes |
| Handlers too generic | Start concrete (quotation-draft, intervention-report); extract patterns later |
| Token budget exceeded | Implement `ContextCompressorAction` check; log and alert |
