## Come Utilizzare Questa Documentazione

Questa documentazione è organizzata in modo da fornire una guida completa all'utilizzo dei server MCP nei progetti Laravel, seguendo le regole di sviluppo e le convenzioni di codice stabilite per i progetti base_predict_fila5.

Per iniziare, si consiglia di leggere l'[Introduzione](00-introduzione-2.md) e seguire le istruzioni di [Installazione](01-installazione-2.md) e [Configurazione](02-configurazione-2.md).

Per gli sviluppatori che desiderano integrare i server MCP nei propri progetti, le sezioni [Utilizzo](03-utilizzo-2.md) e [Integrazione con i Moduli](04-integrazione-moduli-2.md) forniscono esempi pratici e linee guida dettagliate.

Per la risoluzione dei problemi e l'ottimizzazione delle prestazioni, consultare le sezioni [Troubleshooting](06-troubleshooting-2.md), [Best Practices](07-best-practices-2.md) e [Performance](10-performance-2.md).
