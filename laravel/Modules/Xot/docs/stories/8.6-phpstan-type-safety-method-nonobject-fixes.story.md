## Problem Statement

Approximately **67 remaining PHPStan errors** across `laravel/Modules` (L10 strict) fall into three categories:

1. **method.nonObject** (14 errors): Calling method on `mixed` type without type assertion
   - Example: Filament test calling methods on resource stub without asserting type
   - Root cause: Mixed return types from Livewire components, test factories, or app container

2. **argument.type** (16 errors): Passing incompatible type to method
   - Example: `assertArrayHasKey()` expects `mixed` but receives assertion on `mixed` without narrowing
   - Root cause: Unsafe type narrowing in assertion chains

3. **assign.propertyType** (8 errors): Filament Export model expects `class-string<Exporter>` but receives wrong type
   - Example: Test assigns stub instance instead of class string to Export model
   - Root cause: Test mocks/stubs not conforming to Filament API contracts

**Total Impact**: 67 errors blocking zero-error PHPStan compliance across modules.

---

## Goal

Fix all **67 errors** through:
- Type assertions (not casts) for mixed variables
- PHPDoc blocks with correct array/class-string types
- Proper Filament class usage instead of test stubs
- No behavioral changes to code or tests

**Success Criterion**: All modules pass `./vendor/bin/phpstan analyse Modules` at L10 with zero errors.

## Key Files to Address

### Category 1: method.nonObject Errors

**Priority Modules**:
- `Modules/Xot/tests/**/*Test.php`: Exporter mocks, Livewire component testing
- `Modules/Filament/tests/**/*Test.php`: Resource/page testing

**Common Pattern**:
```php
// WRONG - mixed type, no assertion
$exporter = $factory->create();  // returns mixed
$exporter->methodName();         // PHPStan error: method on mixed

// CORRECT - type assertion
$exporter = $factory->create();
assert($exporter instanceof MyExporter);
$exporter->methodName();  // OK
```

### Category 2: argument.type Errors

**Priority Modules**:
- `Modules/*/tests/**/*Test.php`: Test assertion chains
- `Modules/Activity/app/Models/StoredEvent.php`: Array parameter typing

**Common Pattern**:
```php
// WRONG - assertArrayHasKey on mixed
$data = $model->attributes;  // mixed without type declaration
assertArrayHasKey('id', $data);  // Error: expects array but got mixed

// CORRECT - type narrowing first
/** @var array<string, mixed> */
$data = $model->attributes;
assertArrayHasKey('id', $data);  // OK
```

### Category 3: assign.propertyType Errors

**Priority Modules**:
- `Modules/Xot/tests/**/*ExporterTest.php`
- `Modules/*/tests/**/*FilamentTest.php`

**Common Pattern**:
```php
// WRONG - Export expects class-string<Exporter>
$export = Export::create([
    'exporter' => $stub,  // Instance, but expects class-string
]);

// CORRECT - Use FQCN string
$export = Export::create([
    'exporter' => MyExporter::class,  // class-string
]);
```

## Analysis Results (Agent-Driven 2026-10-15)

### Error Patterns Identified

After systematic code analysis across `laravel/Modules`, the 67 errors categorize as follows:

**Category Breakdown**:
- **method.nonObject** (14 errors): Calling methods on `mixed`-typed variables from test factories/containers
- **argument.type** (16 errors): Type mismatches in assertions; array parameters missing generics
- **assign.propertyType** (8 errors): Filament Export API expects `class-string<Exporter>` but receives instances
- **Other** (29 errors): Edge cases (json_decode typing, template generics, etc.)

### Root Cause Analysis

#### 1. method.nonObject Pattern

**Source**: Test factory methods return `mixed` without explicit type hints.

**Example**:
```php
// Modules/Xot/tests/Unit/Exports/XotBaseExporterTest.php:147
$exporter = new XotBaseExporterStub(app(Export::class), [], []);
// app(Export::class) returns mixed; PHPStan error on constructor call
```

**Fix**: Add type assertion immediately after mixed-returning call:
```php
$exporter = new XotBaseExporterStub(app(Export::class), [], []);
assert($exporter instanceof XotBaseExporterStub);
```

#### 2. argument.type Pattern

**Source**: Test data functions return `array` without shape; array accesses become `mixed`.

**Example**:
```php
// Modules/Activity/tests/Unit/EventSourcingBusinessLogicTest.php:129-136
$properties = $activity['properties'];  // returns mixed
Assert::assertArrayHasKey('ip_address', $properties);  // Error: expects array
```

**Issue**: Function `activityEventSourcingActivityData()` has proper PHPDoc, but it's not being recognized at access point.

**Fix (Option A - Variable PHPDoc)**:
```php
/** @var array<string, mixed> */
$properties = $activity['properties'];
Assert::assertArrayHasKey('ip_address', $properties);  // OK
```

**Fix (Option B - More Explicit)**:
```php
/**
 * @var array{
 *     ip_address: string,
 *     user_agent: string,
 *     session_id: string,
 *     old_values: array<string, mixed>,
 *     new_values: array<string, string>
 * }
 */
$properties = $activity['properties'];
```

#### 3. assign.propertyType Pattern

**Source**: Test code assigns Exporter instances instead of class-string to Filament Export model.

**Example**:
```php
// Wrong:
$export = Export::create(['exporter' => new XotBaseExporter()]);

// Correct:
$export = Export::create(['exporter' => XotBaseExporter::class]);
```

**Filament API Contract**: `Export.exporter` field is typed as `class-string<Exporter>`, not instance.

## Implementation Notes

### Type Assertion Pattern (For method.nonObject)

```php
// Pattern 1: Immediate assertion
$var = app(Class::class)->method();
assert($var instanceof ExpectedType);
$var->call();

// Pattern 2: Constructor assertion (most common in tests)
$obj = new ClassName(app(Dependency::class), ...);
assert($obj instanceof ClassName);  // Often unnecessary, but helps PHPStan
```

### Variable PHPDoc Pattern (For argument.type)

```php
// Single-line for simple types
/** @var array<string, string> $data */
$data = $model->attributes;

// Multi-line for complex shapes
/**
 * @var array{
 *     id: int,
 *     name: string,
 *     metadata: array<string, mixed>
 * }
 */
$data = $activity['properties'];
```

### Class-String Pattern (For assign.propertyType)

```php
// Wrong: Instance passed where class-string expected
$export->exporter = new MyExporter();

// Right: Use ::class constant
$export->exporter = MyExporter::class;

// In arrays/create:
Export::create(['exporter' => MyExporter::class])
```
