# BMAD Story 8.4: PHPStan L10 Arr Actions Cleanup: 4 Errors Fixed

**Phase**: 8.4

**Status**: DONE

---

## Summary

Resolved 4 PHPStan L10 errors in Xot module's `Actions/Arr/` directory by:
1. Removing 2 experimental scratch test files
2. Type-narrowing return value in `EnsureKeysAction`

**Result**: Module clean (0 errors at level 10)

---

## Root Causes

### 1. Scratch Test Files (Clutter)
- `ScratchNarrowingTest.php`
- `ScratchNarrowingTest2.php`

**Errors**:
- Line 25: "Cannot cast mixed to string"
- Line 32: "Binary operation "." between mixed and '\x' results in error"
- Line 28: "should return array<string, mixed> but returns array<string>"

**Diagnosis**: These files were experimental type-narrowing explorations, not production code. No callers exist.

**Fix**: Deleted both files (YAGNI).

### 2. EnsureKeysAction Return Type (Inference Failure)
- **File**: `EnsureKeysAction.php`
- **Error**: Line 26: "should return array<int|string, array<string, mixed>> but returns array"

**Root Cause**: `Illuminate\Support\Arr::map()` returns untyped `array`. PHPStan cannot infer the generic type structure.

**Fix**: Replaced `Arr::map()` with explicit `foreach` + `array_replace()`.
- Explicit type narrowing (`is_array($item)` guard)
- Direct control over return type inference
- Same logic, clearer for analyzer
