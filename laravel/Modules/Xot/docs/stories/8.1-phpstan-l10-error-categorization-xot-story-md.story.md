## Key Findings

### 1. "Config Mixed" Family (116 Errors)

**Root Cause**: Laravel's `config()` returns `mixed`. Migration files and actions access config array keys without type narrowing.

**Files Affected**:
- `User/database/migrations/2026_10_05_174817_create_permission_tables.php` (77 errors)
- `Tenant/app/Actions/Json/*.php` (2 errors)

**Pattern**:
```php
$config = config('permission'); // mixed
Schema::create($config['permissions'], ...); // offsetAccess.nonOffsetAccessible
```

**Fix Strategy**: Type config keys early or use type assertion.

---

### 2. "SushiToJson Trait" Family (76 Errors)

**Root Cause**: The `Tenant/app/Models/Traits/SushiToJson.php` trait lacks array generic types. Methods like `getRows()`, `loadExistingData()`, `saveToJson()` return/accept `array` instead of `array<string, mixed>`.

**Files Affected**:
- `Tenant/app/Models/Traits/SushiToJson.php` (context: 3 implementations)
- `Tenant/app/Models/TestSushiModel.php`
- 13 test files using SushiToJson

**Pattern**:
```php
public function getRows() { return $rows; } // return.type: should be array<array<string, mixed>>
public function loadExistingData() { return json_decode(...); } // returns mixed, missing value type
public function saveToJson(array $data) { } // missing $data value type
```

**Also**: `json_decode()` and `json_encode()` are unsafe (thecodingmachine/safe library recommends `Safe\json_decode`).

**Fix Strategy**: Add `array<string, mixed>` to trait, fix test fixtures, use Safe library variants.

---

### 3. "Test Infrastructure / Mockery" Family (54 Errors)

**Root Cause**: Sigma test files use Mockery and Pest factories without proper typing. Log Facade mock expectations call undefined static methods.

**Files Affected**: All 8 Sigma test files.

**Pattern**:
```php
Log::shouldHaveReceived('debug'); // staticMethod.notFound: Log doesn't have this method in Mockery context
$mock->method_call(); // method.nonObject: $mock is mixed, not typed
expect($var)->toBeTrue(); // pest.expectation.redundant: assertion already provable at compile time
```

**Fix Strategy**: Mock typing, Pest assertion cleanup, Log stub setup.

---

### 4. "Array Action Return Types" Family (6 Errors)

**Root Cause**: `Xot/app/Actions/Arr/EnsureKeysAction.php` and test files use loose array types.

**Pattern**:
```php
public function execute(array $data): array { } // should return array<int|string, array<string, mixed>>
```

**Fix Strategy**: Tighten generics.

## Recommended Resolution Sequence

### Phase 8.1: User Migration Config Typing (77 errors, 2-3 hours)

**Root Fix**: Type `config()` return value early in migration.

```php
// Before
$config = config('permission');
Schema::create($config['permissions'], ...);

// After
$config = config('permission') as array<string, string|array>;
// OR
$permissions = (array)config('permission.permissions');
```

**Acceptance**: PHPStan reports 0 errors in User module.

---

### Phase 8.2: Tenant SushiToJson Trait & Tests (76 errors, 3-4 hours)

**Changes**:
1. Add array generics to trait method signatures.
2. Type test fixtures (getRows() → array<array<string, mixed>>).
3. Use `Safe\json_decode` and `Safe\json_encode`.
4. Fix action parameter types in `DeleteJsonFileByRecordAction`, `UpdateJsonFileByRecordAction`.

**Acceptance**: PHPStan reports ≤6 errors (only test-fixture edge cases).

---

### Phase 8.3: Sigma Test Infrastructure (54 errors, 2-3 hours)

**Changes**:
1. Remove redundant Pest assertions (6 errors quick win).
2. Mock Log Facade with proper type stubs.
3. Type Mockery expectations (argument.templateType, method.nonObject).

**Acceptance**: PHPStan reports ≤10 errors (test-only, redundant assertions).

---

### Phase 8.4: Xot Array Actions (6 errors, 30 min)

**Changes**:
1. Add `array<int|string, array<string, mixed>>` to EnsureKeysAction.
2. Type test fixtures.

**Acceptance**: PHPStan reports 0 errors in Xot.
