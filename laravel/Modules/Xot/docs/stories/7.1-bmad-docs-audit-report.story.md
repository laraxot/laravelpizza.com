## Consolidation Opportunities

### 1. Duplicate/Variant Filenames

**Problem:** Some modules have .md files with same content but different naming  
**Examples:**
- Lang: `advanced-language-switching.md` vs `advanced_language_switching.md`
- UI: `advanced-form-components.md` vs `advanced_form_components.md`

**Action:** Consolidate to one filename, update all references

### 2. Root-Level Orphaned Docs

**Problem:** 41 (Activity), 43 (Lang), 29 (Job), 18 (Xot), 14 (UI) .md files scattered in `docs/` root  
**Impact:** Violates BMAD structure (docs should live in `stories/`, `wiki/`, or `bmad/`)

**Action:** Audit each file, migrate to appropriate subdirectory

### 3. Missing decision-log.md

**Problem:** Modules without formal decision tracking  
**Affected:** Activity, Job, Lang, Media, Notify, UI (Xot)

**Action:** Add template `docs/bmad/decision-log.md` to track major architectural decisions

### 4. Orphaned Audit Files

**Problem:** Xot has `_AUDIT_REPORT.json`, `_AUDIT_REPORT_DETAILED.json`, and underscore variants (×4 total)  
**Action:** Archive to separate location or consolidate
