# GSD Canonical Source

## Regola

Nel progetto, `GSD` significa sempre **Get Shit Done**:

- repository canonico: https://github.com/gsd-build/get-shit-done
- documentazione canonica: https://gsd-build-get-shit-done.mintlify.app/

Per il modulo Xot, questa regola conta per governance tecnica, refactor cross-modulo, quality gate e lavoro su classi base. Non usare `GSD` come shorthand generico.

## Uso con Xot

- BMAD chiarisce story, requisiti e vincoli architetturali.
- GSD organizza piani, wave execution e verifiche.
- Ruflo conserva checkpoint e memoria operativa.
- Le modifiche a Xot restano forward-only: niente revert, solo correzioni incrementali.
