## Summary
Consolidate scattered .md files and folder structures across Laravel modules into unified docs/ organization pattern. Affects all 18 modules; focus on priority modules first (Ptv 114, Pdnd 57, Performance 35 orphan files).

## Scope
- **Priority 1**: Ptv (114 orphan files), Pdnd (57), Performance (35)
- **Priority 2**: Remaining 15 modules (30 total orphan files)
- **Total scope**: 1200+ orphan .md files across all modules

## Current State
Modules have scattered folder patterns:
- Root-level .md files (orphan at docs/ root)
- Duplicate folder structure (e.g., brainstorming/ + bmad/brainstorming/)
- Empty service-specific folders (Pdnd: c003-, c015-, c030-, c007-*)
- Missing or incomplete bmad/, wiki/ organization

## Actions per Module
1. List orphan .md files at root level
2. Categorize by content type (design, architecture, memory, etc)
3. Move design/architecture → docs/bmad/
4. Move memory/concepts → docs/wiki/
5. Merge duplicate folders
6. Remove empty folders
7. Create/update docs/README.md with structure
8. Git commit per module

## Architecture
```
docs/
├── README.md (module overview)
├── bmad/
│   ├── architecture/ (design decisions, patterns)
│   ├── brainstorming/ (working notes)
│   ├── epics/ (epic definitions)
│   ├── stories/ (completed stories)
│   └── rules/ (module rules)
├── wiki/
│   ├── concepts/ (technical concepts)
│   └── rules/ (working rules)
├── purpose.md (mandatory module intro)
└── [other organized content]
```
