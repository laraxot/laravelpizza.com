# 5.128: Correzione max 5 .md in root per tutti i moduli

## Story

Come manutentore dell'architettura laraxot, voglio che ogni modulo abbia
al massimo 5 file `.md` in root (README.md, CHANGELOG.md, LICENSE.md,
AGENTS.md, CLAUDE.md). I file `.md` extra vanno spostati in `docs/` con
naming standard. I duplicati di solo maiuscola vanno rimossi.

## Perché (second brain + regola)

- `laravel/Modules/Xot/docs/wiki/concepts/module-theme-root-hygiene.md` (SSoT):
  solo 3 file ammessi in root (`README.md`, `CHANGELOG.md`, `LICENSE.md`).
- `bashscripts/ai/wiki/memories/module-theme-root-hygiene.md` (memory):
  root modulo/tema: solo cartelle lowercase, un `_*.code-workspace`, zero
  `.cursor`/`.vscode`/`.windsurf`/`.devcontainer`.
- Story 5.126 (`root-md-max5-verify.story.md`) definisce i criteri di
  accettazione per la verifica.

## Acceptance Criteria

1. Max 5 file `.md` in root per ogni modulo
2. Solo i file ammessi (README.md, CHANGELOG.md, LICENSE.md, AGENTS.md, CLAUDE.md) presenti in root
3. Contenuto dei file spostati conservato (merged se gemello in `docs/`)
4. Gate `verify-module-root-hygiene.sh` passa per tutti i moduli
5. Nessun file `.md` con date/timestamp nel nome
6. Ogni file `.md` ha YAML frontmatter
7. Ogni file `.md` e' indicizzato da qmd (docs/README.md o docs/index.md)
