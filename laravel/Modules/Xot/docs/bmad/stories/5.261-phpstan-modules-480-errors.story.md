# PHPStan Modules 2026-10-05: baseline 480 errori / 68 file

## Contesto

Richiesta utente: `cd laravel && ./vendor/bin/phpstan analyse Modules` e sistemare
**tutte** le segnalazioni, massima qualità, con BMAD + second brain.

## Root cause analysis (le 10 famiglie di errore)

1. **56× `argument.templateType`**: "Unable to resolve the template type TValue in
   call to function expect": `expect()` di Pest su espressioni `mixed`
   (`json_decode()` senza tipo, `Arr::get()` senza default tipizzato). Le regole
   di progetto vietano `expect()` nei file Pest → vanno convertite in
   `PHPUnit\Framework\Assert::assert*()` con narrowing esplicito.
2. **39× `method.notFound` su `TestSushiModel::saveToJson()`**: il metodo non
   esiste sul modello: i test chiamano un'API del trait `SushiToJson` che è stata
   rinominata/spostata (oggi in `Create/Update/DeleteJsonFileByRecordAction`).
   È un **bug di test che maschera un bug di design**: i test chiamano azioni che
   non esistono più.
3. **27× `theCodingMachineSafe.function`** (`json_encode`/`file_get_contents`/
   `preg_match` "unsafe"): vietato il ritorno `false`: servono le varianti con
   `\Safe\` o gestione esplicita del fallimento.
4. **27× `offsetAccess.nonOffsetAccessible`** + **13× `method.nonObject`** -
   `mixed` non strettato dopo `json_decode()` / `Arr::pluck()`.
5. **25× `FilesystemAdapter::put()` con `string|false`**: `json_encode()` può
   restituire `false`: è la stessa radice di (3).
6. **13+11+4× `argument.type` su `$service`**: `CallWebServiceAction::execute()`
   e `TestConnectionAction::execute()` dichiarano `WebService`, i test passano
   `MockInterface`: serve uno stub/istanza reale o `@return WebService` sul mock.
7. **12+12+4× `sushiRowById()/jsonRecordAt()` con `mixed`**: helper di test che
   restituiscono `mixed` perché leggono da json non tipizzato.
8. **7× `Log::shouldHaveReceived()`**: metodo statico inesistente: serve
   `Log::spy()` + `Log::shouldHaveReceived()` via facade mockata correttamente,
   oppure pattern equivalente del progetto.
9. **4× `property.notFound` su `Mockery\MockInterface::$endpoint`**: accesso a
   proprietà dinamiche di un mock non stubbato.
10. **Filament v5 namespace migration**: `Filament\Forms\Components\Component`
    non esiste in v5 (è `Filament\Schemas\Components\Component`), `Action::form()`
    è deprecato.
