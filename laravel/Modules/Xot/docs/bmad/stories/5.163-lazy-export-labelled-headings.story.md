# 5.163: canale lazy = path in intestazione

## Story

As a maintainer,
I want the lazy export channel to honour `path => title` like `CollectionExport`,
so that switching a large list to `ExportXlsLazyAction` does not resurrect
`ratings_by_id.52.pivot.value` in the header.

## Perche'

`ExportXlsAction` (montato su `BaseListSchedas`) usa `CollectionExport` e
tiene le label. `ExportXlsLazyAction` documenta gia' nel PHPDoc:

> le intestazioni esplicite (chiave stringa => label) non sono supportate
> e degradano al path.

`resolvePathFields()` schiaccia a `array<int, string>` (solo path).
`ExportXlsByQuery` / `ByLazyCollection` / `Stream` non hanno il contratto misto.

Oggi `BaseListSchedas` non monta il lazy. Rischio: un "ottimizza export grandi
liste" riattiva il bug del prompt 03 (title rating).

## Acceptance Criteria

1. Lazy (o stream) accetta `array<int|string, string>` misto come
   `CollectionExport::headings()`.
2. Test senza DB: stessi fields stub → headings === title, non path.
3. PHPStan 0. Non `array_values()` sui fields (distrugge le chiavi stringa).

## Tasks

- [ ] Leggere `resolvePathFields` + i 3 execute lazy
- [ ] Allineare a `CollectionExport` (DRY: riusare headings/map, non un terzo formato)
- [ ] Test Xot
