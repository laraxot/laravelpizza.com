## Note
L'errore "unexpected token <<" era dovuto a merge conflict marker non risolti nelle string heredoc:
```php
    ... codice ...
```

(Esempio indentato di proposito: i marker a inizio riga farebbero scattare i gate fleet-wide di scansione dei conflitti.)
PHP interpreter non riconosce questo come heredoc valido e fallisce al primo `<<`.
