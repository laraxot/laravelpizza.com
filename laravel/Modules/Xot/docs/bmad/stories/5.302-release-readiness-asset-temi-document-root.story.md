# Release readiness: asset temi, document root, test nei moduli

## Contesto

Richiesta utente (2026-11-11): portare il progetto pronto al rilascio in
produzione, correggendo e migliorando senza attendere conferme. Indicazioni
esplicite:

- `public_html/` è la document root, non va mai cancellata.
- `public_html/themes/<Tema>` deve essere `ln -s ../../laravel/Themes/<Tema>/public`;
  `npm run copy` non serve più.
- Non usare `laravel/tests/`: ogni modulo ha la propria cartella `tests`.

## Evidenze (verificate sul codice, branch dev @ 89eff7ff)

| # | Problema | Gravità |
|---|----------|---------|
| 1 | `public_html/hot` versionato con `http://127.0.0.1:5173`: in produzione `@vite` carica CSS/JS dal dev server → pagine senza stile | P0 |
| 2 | `public_html/info.php` con `phpinfo()` raggiungibile da web | P0 sicurezza |
| 3 | `.htaccess` forza `SetHandler application/x-httpd-php` anche senza mod_php → su PHP-FPM i `.php` possono essere serviti come testo | P1 sicurezza |
| 4 | `public_html/themes/` ignorata da git: niente symlink versionati, servivano copie manuali | P1 |
| 5 | `Themes/Zero/package.json` conserva `"copy": "cp -r ./public/* …"` | P2 |
| 6 | `laravel/tests/` contiene 18 test + bootstrap; `phpunit.xml` esegue **solo** `tests/`, quindi i test dei moduli non sono nella suite di default | P1 |
| 7 | ~240 test di modulo importano `Tests\TestCase` (root) invece del TestCase del modulo | P1 |

## Acceptance criteria

- [x] AC1 `public_html/themes/{One,Zero}` symlink relativi versionati; `.gitignore` aggiornato.
- [x] AC2 `public_html/hot` e `info.php` rimossi e ignorati.
- [x] AC3 `SetHandler` in `.htaccess` dentro `<IfModule php_module>`.
- [x] AC4 Script `copy` rimosso dal tema Zero.
- [x] AC5 Regola SSoT `Xot/docs/wiki/rules/theme-public-symlink.md` + test Pest `Xot/tests/Unit/ThemePublicSymlinkTest.php`.
- [ ] AC6 Test di `laravel/tests/` spostati nei moduli proprietari, duplicati/tautologici eliminati.
- [ ] AC7 Test di modulo su `Modules\<Mod>\Tests\TestCase`; `phpunit.xml` esegue `Modules/*/tests`.
- [ ] AC8 Pest verde sui test toccati; PHPStan 0 errori sui file toccati.

## Note di decisione

- **`FollowSymLinks` non aggiunto a `.htaccess`**: `mod_rewrite` lo richiede già
  attivo, e dichiarare `Options` senza `AllowOverride Options` produce 500.
- **Tema One**: non ha build Vite propria e riusa `themes/Zero` di proposito;
  link creato comunque perché `Themes/One/public` esiste.
- **Lock / `bashscripts/`**: non presenti nel clone (repo separato, gitignored);
  coordinamento tramite questa story.

`ModulesArchitectureTest` cercava i moduli in `dirname(__DIR__, 2).'/Modules'`,

Con la radice giusta il gate trova 3 violazioni vere, tutte arrivate con i
commit `.` di Marco del 2026-11-11 nei repo dei moduli:

  `Xot/app/Services/Artisan/Handlers/ModuleCommandHandler.php`, cancellati il
  2026-10-20 (`398a78fa1d`) e riportati dal merge `48c9075afc` (stato `AA`).
  Nessun riferimento nel codice: sono codice morto, il `ModuleCommandHandler`

attesa dell'ok dell'utente.
