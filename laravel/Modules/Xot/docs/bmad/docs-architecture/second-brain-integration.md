# Second Brain

Second Brain/Hindsight conserva il perché, le convenzioni e le correzioni durevoli;
il repository conserva i documenti verificabili. Non si usa la memoria per
affermare che una pagina o una parity è corretta senza controllare il codice e
l'evidence corrente.

Alla fine di un lavoro significativo si salva una nota con:

- obiettivo e perimetro;
- decisioni e motivazioni;
- file/documenti canonici;
- cosa è stato verificato e cosa resta aperto;
- eventuali correzioni a memoria precedente.

Le pagine Hindsight vuote o obsolete non sono SSoT: si aggiornano solo con fatti
duraturi e si registra una `Correction:` quando il codice smentisce una memoria.
