# Manuale utente Xot

Integra il [manuale actor-oriented](../manuale-uso-attori.md). Xot fornisce infrastruttura condivisa, basi dei moduli e convenzioni.

## Attori e uso

| Attore | Uso verificato |
|---|---|
| Utente normale/gruppo | Beneficia indirettamente dei contratti Xot usati dai moduli. |
| Admin | Usa le superfici del modulo owner che estendono Xot. |
| Super-admin | Governa le pagine infrastrutturali esposte e autorizzate. |

Xot non va usato per aggirare policy del modulo owner.
