# 4.26: PHPStan regression remediation: Job

## Story

As a maintainer, I want Job's command and scheduling tests made type-safe and meaningful, so that the module closes its part of the global regression.

## Acceptance Criteria

<!-- LOCKED -->
1. All 77 Job findings (1 production, 76 test) are resolved at root cause without suppressions or edits outside Job.
2. `TestJobCommand.php` and retained scheduling/policy tests preserve real behaviour; protected/internal APIs are not exposed solely for tests.
3. Tautological and imaginary-API tests are removed or rewritten, with disposition counts recorded.
4. The canonical full PHPStan run attributes zero findings to Job with clean bootstrap/stderr.
5. Existing Job coverage/testing docs are updated DRY.
