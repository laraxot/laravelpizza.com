# Naming Convention Cartelle Blocks

> **Fonte**: https://flowbite.com/blocks/ e https://tailwindcss.com/plus/ui-blocks

## Regola Fondamentale

I nomi delle sottocartelle in `laravel/*/*/resources/views/components/blocks/` **DEVONO** essere presi esclusivamente da:

1. **Flowbite Blocks**: https://flowbite.com/blocks/
2. **Tailwind UI Blocks**: https://tailwindcss.com/plus/ui-blocks

## Convenzione Nomi File

- **Singolare**: `hero.blade.php` (non `heroes.blade.php`)
- **Kebab-case**: `star-rating.blade.php` (non `starRating.blade.php`)
- **Suffisso**: `.blade.php` obbligatorio
- **Variante default**: `default.blade.php`
