# Media: risoluzione dei marker di merge committati in e7e667b11

## Fase BMAD: Docs/Review (fase D), dopo Build + Measure (batch 05, 06, 07)

## Problema

Il commit `e7e667b11` ha portato nel repo un merge `HEAD` vs `laraxot/dev` con i
marker `<<<<<<<` / `=======` / `>>>>>>>` non risolti. In `Modules/Media` erano
coinvolti 92 file PHP (app, lang, migrazioni, test) e 6 file `.md` in `docs/` e
nella root del modulo. Con i marker, PHPStan e Pest non potevano nemmeno
caricare i file.

Causa radice gia' diagnosticata per la fleet in
[media-docs-conflict-marker-cleanup-2026-09-22](./media-docs-conflict-marker-cleanup.story.md):
il daemon locale di auto-commit fa merge con un remote divergente e committa i
marker. Questa story e' la ricorrenza del 2026-10-06.

## Regola di risoluzione

- Il lato `HEAD` e' la baseline PHPStan a zero errori; il lato upstream
  (`laraxot/dev`, "theirs") e' stato adottato solo dove i simboli che usa esistono
  davvero nel codice (`GetFilesystemAdapterAction`, `Lang::string()`,
  `Modules\Xot\Contracts\UserContract`, `MediaExporterResolver`, ...).
- Ogni file e' stato valutato per scopo (campo `purpose` dei report batch), non per
  hunk alla cieca. Nei file in conflitto il lato `ours` era la versione
  pre-cleanup (errori `constantTypeCoverage`, `assign.overwritten`,
  `variable.unused` gia' risolti in theirs): nessun file ha tenuto `ours` intero.
- Dove theirs introduceva una regressione, e' stato fuso a mano (6 file).
- Nei file lang i placeholder (`Missing Label`, nome-chiave grezzo) sono stati
  sostituiti dalla traduzione reale nella lingua della cartella.

## Decisioni notevoli

1. **`ConvertVideoCommand`**: theirs. Una sola transcodifica (ours salvava due volte e
   duplicava `new WebM`); URL del file via `GetFilesystemAdapterAction`.
2. **`S3Test` / `TestBucketPermissionsAction`**: theirs. La pagina delega a
   `TestBucketPermissionsAction` (via ~60 righe duplicate e l'`assign.overwritten`).
   Coerente con la story [phpstan-zero-errors-media](./phpstan-zero-errors-media.story.md).
3. **`AwsTest`**: theirs. Il test file-operations confronta il contenuto scaricato con
   quello caricato.
4. **`UserContract` (merged in `MediaBusinessLogicTest`; stesso contratto in `StreamVideoAction`)**:
   theirs importava `Modules\User\Contracts\UserContract`, un alias che nessun model
   implementa, quindi `instanceof` sempre falso nel test. Si usa il contratto SSoT
   `Modules\Xot\Contracts\UserContract`. In `Media.php` l'import `UserContract` inutilizzato e' stato rimosso.
5. **`Media.php` (merged)**: docblock e import di theirs, ma costruzione esplicita di
   `MediaCollection<int, Media>` (robusta con Larastan).
6. **`MediaTable.php` (merged)**: theirs, ma `is_string` al posto di `Assert::string`:
   `mime_type` e' nullable e `Assert` avrebbe lanciato sul filtro.
7. **`VideoStream.php`, `StreamVideoAction.php` (merged)**: theirs piu' rimozione
   dell'import `Storage` rimasto inutilizzato; accesso ai dischi tipizzato con
   `GetFilesystemAdapterAction`.
8. **`ConvertController.php` (merged)**: base theirs (estende `BaseController` del
   modulo), formattazione ripulita; nessuna route lo usa.
9. **`Lang::string()`** al posto di `__()`/`trans()` nelle pagine e request del modulo
   (garantisce `string` per PHPStan max).
10. **Docs (6 file)**: `README.md` (root modulo), `docs/README.md`, `docs/bmad/coverage.md`,
    `docs/bmad/quick-reference.md`, `docs/bmad/brainstorming.md`, `docs/bmad/setup-guide.md`.
    Per ogni file un solo documento coerente con le informazioni uniche di entrambi i
    lati; fatti rivalutati sul codice (migrazioni 6 e non 3 o 13, provider da
    `composer.json`, `composer clear`/`fix-storage` non esistenti rimossi, link rotti
    corretti, template vuoto di brainstorming scartato).

## Verifica

- Marker residui nel modulo: `grep -rlE '^(<<<<<<< |>>>>>>> )' laravel/Modules/Media` ->
  nessun file (esclusi vendor e node_modules).
- `php -l` su `app/`, `tests/`, `lang/`, `database/` (file non vuoti): nessun errore di sintassi.
- `./vendor/bin/phpstan analyse Modules/Media`: `[OK] No errors` (exit 0, eseguito il
  2026-10-07). Per l'intero albero `analyse Modules` exit 0, `[OK] No errors`.

## Followups aperti

Verificati nel codice corrente il 2026-10-07 (i report batch sono stati scritti mentre
altri file cambiavano). Ordinati per priorita'.

### Alta

1. **`ConvertVideoAction::execute()` salva due volte** (verificato): prima
   `toDisk()/inFormat()/save()` e poi una seconda catena con un `X264` senza
   `setKiloBitrate`, che sovrascrive il file. Applicare la stessa semplificazione "una
   sola transcodifica" di `ConvertVideoCommand`, tenendo il bitrate 1000.
   File: `app/Actions/Video/ConvertVideoAction.php`.
2. **Chiavi lang `media::attachments.types.*` e `media::attachments.type_notes.*`
   senza file** (verificato): `AttachmentTypeEnum` le legge, ma non esiste nessun
   `lang/*/attachments.php`, quindi label e note ricadono sul nome-chiave grezzo.
   Esiste `lang/it/attachment_type_enum.php` (chiavi `values.*`), usato da `EnumTrait`:
   decidere se allineare l'enum a quel file o creare `attachments.php`.

### Media

3. **`SubtitleService` duplicato** (verificato con `diff`: identici salvo namespace):
   `app/Services/SubtitleService.php` e `app/Actions/Stream/SubtitleService.php`. La
   prima viola la regola no-services. Consolidare in un'unica Action e aggiornare
   `tests/Unit/MediaHighestMissCoverageTest.php` (referenzia la classe). Vedi
   [media-services-to-actions](./media-services-to-actions.story.md).
4. **`MediasTable` accanto a `MediaTable`** (verificato):
   `app/Filament/Resources/MediaResource/Tables/MediasTable.php` non e' referenziata
   dall'app (`getTableClass` risolve `MediaTable` perche' `Str::plural('Media')` e'
   `Media`), ma e' importata da `tests/Unit/MediaFilamentAndActionsTest.php`. Rimuovere
   o unire con `MediaTable` aggiornando il test.
5. **Directory case-variant residue** (verificato, aggiorna la story
   [16-4](./16-4-media-case-variant-consolidation.md)): nel working tree `tests/unit` e
   `tests/feature` (minuscolo) risultano rimosse (cancellazioni non ancora committate),
   restano `tests/filament` vs `tests/Filament` (con `MediaConvertResourceTest.php` vs
   `mediaconvertresourcetest.php` in entrambe) e `app/conversions` vs `app/Conversions`.
6. **File spuri tracciati** (nuovo, verificato): `app/Filament/Clusters/极est/Pages/AwsTest.php`
   (0 byte, nome directory corrotto) e residui `app/Services/*.bak`,
   `app/Support/TemporaryUploadPathGenerator.php.bak`,
   `app/Actions/Image/SvgExistsAction.to_xot`.

### Bassa

   - `lang/it/temporary_upload.php`: `label` = `Temporary Upload`, `plural_label` =

8. **Import inutilizzati preesistenti** (verificato, non bloccanti):
   `Filament\Schemas\Schema` in `app/Filament/Clusters/Test/Pages/S3Test.php`;
   `Illuminate\Database\Eloquent\Factories\Factory` in `app/Models/Media.php`.
9. **Sonde inline in `S3Test`** (parzialmente verificato): `test_s3_permissions` delega a
