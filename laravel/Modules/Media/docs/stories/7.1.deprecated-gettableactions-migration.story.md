# Story 7.1: Migrate Deprecated getTableActions() → table(): Media Module

**Status**: awaiting-analysis  
**Module**: Media  
**Pattern**: Filament v4→v5 API migration  
**Errors known**: 2 (getTableActions() deprecated)  
**Effort**: small  
**Owned by**: TBD

## Problem

Filament v5 deprecated `getTableActions()` method. Replaced with new `table()` pattern or schema-based approach.

**Known occurrences**: 2 in Media module (exact files TBD)

## Workflow

1. **Locate all occurrences**:
   ```bash
   grep -rn "getTableActions" Modules/Media --include="*.php"
   ```

2. **For each occurrence**:
   - Read context (which class, what it returns)
   - Understand what the old API did
   - Convert to v5 equivalent (likely schema-based)
   - Verify type hints

3. **Filament v5 reference**:
   - Check Filament 5 docs for table actions pattern
   - May need to move logic from getTableActions → table() method
   - Or use new `->actions([...])` API

4. **Fix**:
   - Replace deprecated calls
   - Update imports if needed
   - Ensure compatibility

5. **Verify**:
   ```bash
   phpstan analyse Modules/Media --no-progress
   pest Modules/Media/tests -c Modules/Media/phpunit.xml --no-coverage
   ```

6. **Git sync**

## Success Criteria

- PHPStan: 0 errors (post-Cms unblock)
- No getTableActions() references remain
- Pest: all pass
- Git: clean
