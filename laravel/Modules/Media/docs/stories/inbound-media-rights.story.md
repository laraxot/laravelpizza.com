# Diritti e accessibilità dei media editoriali

## Richiesta / scopo
Come redazione voglio pubblicare cover e allegati con diritti verificati, testo alternativo utile e dimensioni adeguate.

## Acceptance Criteria
- [ ] Ogni media pubblicato ha titolarità/licenza e scadenza quando applicabile.
- [ ] Il testo alternativo descrive lo scopo e non duplica la didascalia.
- [ ] Immagini decorative e informative sono distinguibili.
- [ ] Il tema non nasconde informazioni essenziali solo nell'immagine.

## Tasks / Subtasks
- [ ] Riutilizzare metadata Media esistenti.
- [ ] Aggiornare checklist editoriale.
- [ ] Verificare card e dettaglio nei temi.

## Owned File / Module Scope

## Testing / Verifica
