# Media PHPStan zero: method.staticCall

## Fase BMAD: Build + Measure

## Contesto

Precedenti sessioni (2026-09-04, 2026-09-06) avevano gia' portato
`phpstan analyse Modules/Media` a 0 errori sistemando cast e generics.
Una scansione full-tree del 2026-09-07 ~19:08 ha rilevato una regressione:
8 nuovi errori `method.staticCall`, introdotti quando le classi
`Schemas/{Model}Form` e `Schemas/{Model}Infolist` sono state convertite da
metodi statici a metodi d'istanza (pattern comune a molti moduli in questo
refactor epocale: `XotBaseResourceForm::getFormSchema()` e
`XotBaseResourceInfolist::getInfolistSchema()` sono astratti **non statici**,
si risolvono via `app(static::class)` in `configure()`), senza aggiornare i
chiamanti che restavano `ClassName::getFormSchema()`.

## Causa radice

`Modules\Xot\Filament\Resources\Schemas\XotBaseResourceForm::getFormSchema()`
e' `abstract public function getFormSchema(): array` (istanza, non
static). Stesso per `XotBaseResourceInfolist::getInfolistSchema()`.
Quattro punti nel modulo Media chiamavano ancora questi metodi in stile
statico (`MediaConvertForm::getFormSchema()` ecc.), un residuo della vecchia
API prima della migrazione a `Schemas/` dedicate.

## Errori trovati (8, error-format=json, phpstan.neon invariato)

| File | Riga | Chiamata errata |
|---|---|---|
| `app/Filament/Resources/MediaResource/Schemas/MediaInfolist.php` | 46 | `MediaConvertForm::getFormSchema()` |
| `tests/Unit/Filament/MediaConvertSchemasTest.php` | 31, 46, 58 | `MediaConvertForm::getFormSchema()` |
| `tests/Unit/MediaFilamentAndActionsTest.php` | 27, 39, 44 | `MediaForm::getFormSchema()`, `TemporaryUploadForm::getFormSchema()`, `HasMediaForm::getFormSchema()` |
| `tests/Unit/MediaHighestMissCoverageTest.php` | 223 | `MediaInfolist::getInfolistSchema()` |

## Soluzione applicata

Sostituita ogni chiamata statica con la risoluzione via container,
convenzione gia' in uso in `Modules/Geo`, `Modules/Activity`, `Modules/Notify`,
`Modules/Tenant`:

```php
// prima
$schema = MediaConvertForm::getFormSchema();

// dopo
$schema = app(MediaConvertForm::class)->getFormSchema();
```

Nessuna alternativa scartata: e' l'unico pattern coerente col resto del
repo, non introduce un nuovo metodo statico sulla classe base (che
romperebbe il contratto `abstract public function` di
`XotBaseResourceForm`/`XotBaseResourceInfolist` e la firma richiesta da
`HasXotForm::form()`).
