# Story 16.5: Install and integrate spatie/laravel-medialibrary

## GitHub (tracciamento)

| Risorsa | URL | Stato |
|---------|-----|-------|
| Issue | https://github.com/laraxot/base_techplanner_fila5/issues/56 | OPEN |

## Context

**Problem**: Media modulo manca core dependency `spatie/laravel-medialibrary`.

**Symptoms**:
- No polymorphic media collections support
- No automatic image conversions (WebP, AVIF, thumbnails)
- No CDN integration built-in
- FFmpeg pipeline (pbmedia/laravel-ffmpeg) works standalone, but no unified media abstraction

**Why matters**: Media modulo should be the canonical media layer for Laraxot ecosystem. Without medialibrary, every consuming module reinvents collections/conversions/CDN handling independently.

## Deliverables

### 1. Add spatie/laravel-medialibrary to composer.json
- Package version: `^11.0` (current stable, Filament 5 compatible)
- Installation: `cd laravel && composer require spatie/laravel-medialibrary`
- Commit: "Add spatie/laravel-medialibrary as core Media dependency"

### 2. Create ServiceProvider integration
File: `laravel/Modules/Media/app/Providers/MediaServiceProvider.php`

Requirements:
- Publish medialibrary config: `php artisan vendor:publish --provider="Spatie\MediaLibrary\MediaLibraryServiceProvider" --tag="config"`
- Register Filament form component for media input (see below)
- Declare medialibrary database migration as publishable
- Document in module's ServiceProvider how consuming modules register media models

### 3. Create Filament media form component
File: `laravel/Modules/Media/app/Filament/Forms/Components/MediaInput.php`

Usage in consuming modules:
```php
use Modules\Media\Filament\Forms\Components\MediaInput;

MediaInput::make('media')
    ->label('Upload Media')
    ->collection('default')
    ->acceptedFileTypes(['image/jpeg', 'image/png', 'video/mp4'])
```

Requirements:
- Extend `XotBaseField` (for native Filament integration)
- Support single/multiple file collections
- Support file type restrictions
- Support lazy loading via `spatie/laravel-medialibrary` lazy collection

### 4. Update docs/RECOMMENDED_PACKAGES.md
File: `laravel/Modules/Media/docs/RECOMMENDED_PACKAGES.md`

Content per package:

**spatie/laravel-medialibrary**
- What: Polymorphic media collections, automatic conversions, CDN abstraction
- Why for Media: Canonical abstraction for all media operations (images, videos, documents)
- Pros: +Conversions (WebP/AVIF), +Polymorphic support, +Lazy loading, +CDN agnostic
- Cons: −New dependency, −Database migration required
- Installation: `composer require spatie/laravel-medialibrary:^11.0`
- Example usage:
  ```php
  // In model
  use Spatie\MediaLibrary\HasMedia;
  use Spatie\MediaLibrary\InteractsWithMedia;

  class Product extends BaseModel implements HasMedia {
      use InteractsWithMedia;
  }

  // Register collection with conversions
  $product->registerMediaCollections();
  $product->registerMediaConversions();

  // Attach media
  $product->addMedia($file)->toMediaCollection('images');

  // Get conversions
  $product->getMedia('images')->first()->getUrl('thumb');
  ```

**pbmedia/laravel-ffmpeg** (already present)
- Keep as-is for FFmpeg operations
- Medialibrary + FFmpeg integration: Chain FFmpeg processing in medialibrary conversions

**intervention/image** (already present)
- Keep as-is for image manipulation
- Medialibrary uses intervention/image internally for thumbnails
