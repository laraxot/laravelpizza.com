# Story 4.1 — Fix PHPStan L10 generics.notGeneric in Activity

## Context

PHPStan L10 Modules scan reveals `generics.notGeneric` errors in Activity models. Error pattern:

```
PHPDoc tag @use contains generic type ... but trait ... is not generic
```

Affects: Activity.php, Snapshot.php, StoredEvent.php (minimum 3 models)

Root cause: HasXotFactory trait declares non-generic @use with generic factory type in PHPDoc.

## Acceptance Criteria

- [ ] Audit all Activity models with @use + HasXotFactory
- [ ] Remove generic type hints from @use declarations (or make trait generic)
- [ ] PHPStan L10: 0 generics.notGeneric errors in Activity app/
- [ ] Run pest Activity/tests --no-coverage + increment coverage in docs/coverage.md
- [ ] Git commit + push to all Activity remotes

## Testing

```bash
cd laravel && ./vendor/bin/phpstan analyse Modules/Activity --memory-limit=-1
./tools/phpmd.sh Modules/Activity
./vendor/bin/pest Modules/Activity/tests --no-coverage
```
