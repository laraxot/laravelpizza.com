## User story

As a developer maintaining Activity tests,
I want `tests/Pest.php` to bind the module TestCase via `pest()->extend()` instead of `require_once PestStubs.php`,
so that bootstrap Pest 5 is idiomatic and runtime stubs are replaced by official plugins.

## Acceptance criteria

1. `Modules/Activity/tests/Pest.php` usa `pest()->extend(\Modules\Activity\Tests\TestCase::class)` con `@phpstan-ignore method.internalClass` inline — **no** `require_once`.
2. `PestStubs.php` rimosso (plugin `pest-plugin-laravel` / `pest-plugin-livewire` via Xot).
3. Pilota in `tests/Unit/Bootstrap/PestExtendBootstrapTest.php` — **5 test verdi** con comando canonico modulo.
4. Docs Activity aggiornati: `wiki/concepts/pest-bootstrap-extend-ignore.md`, `testing.md`.
5. PHPStan su `Pest.php`: ignore inline sufficiente; gate globale bloccato da duplicate `includes:` in `phpstan.neon` (fix utente).

## Implementazione (stato)

| File | Azione |
|------|--------|
| `tests/Pest.php` | `pest()->extend(...)->in('Unit/Bootstrap')` + ignore |
| `tests/PestStubs.php` | **Eliminato** |
| `tests/Unit/Bootstrap/PestExtendBootstrapTest.php` | **Nuovo** — meta + binding + factory |
| `phpunit.xml` | `bootstrap="../../vendor/autoload.php"` (allineato Media) |

## Comando test (LOCKED)

Pest carica `Modules/*/tests/Pest.php` solo se `--test-directory` punta alla cartella tests del modulo:

```bash
cd laravel
./vendor/bin/pest -c Modules/Activity/phpunit.xml \
  --test-directory=Modules/Activity/tests \
  --filter=PestExtendBootstrap --no-coverage
```

**Nota:** `pest()->extend` su `Unit/Feature` intero conflitte con i file che dichiarano ancora `uses(TestCase::class)`. Migrazione full-module = story futura; pilota limitato a `Unit/Bootstrap`.

## Dev guardrails

- **Non** bindare `XotBaseTestCase` abstract.
- **Non** creare `.neon` aggiuntivi — solo ignore inline su `Pest.php`.
- **Non** reintrodurre `tests/Support/` o `require_once` cross-modulo.
- Helper condivisi: `Modules\Xot\Tests\XotBasePest` (PSR-4 statico).

## Architecture compliance (ADR-017)

Eccezione esplicita Activity: preferire `extend` + ignore inline a `require_once`. Altri moduli: gate PHPStan senza ignore (story 3.7 Rating pilota).

## Testing requirements
