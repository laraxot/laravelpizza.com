# Story 7.1-ACTIVITY — Contratti PHPStan azioni e test

## Story

Come maintainer Activity, voglio chiudere i contratti residui di redazione, lista log e test event sourcing, affinché il modulo sia verde senza indebolire l'audit trail.

## Acceptance Criteria

<!-- LOCKED. External dev tools must not edit Acceptance Criteria. -->

1. PHPStan su `Modules/Activity` termina con zero errori.
2. RedactModelAttributesAction e ListLogActivities hanno input/callback concreti senza cambiare redazione o visibilità.
3. ActivityEventSourcingTest e ActivityIntegrationTest usano callback tipizzate e asserzioni semantiche.
4. Immutabilità, connection `activity` e audit append-only restano invariati.
5. Nessun ignore, config, baseline, stub locale, Service nuovo o `mixed` evitabile è introdotto; doc canonica aggiornata.

## Tasks / Subtasks

- [x] Catturare baseline e separare applicazione/test (AC: #1, #2, #3)
- [x] Correggere Action/Page e i due test senza alterare audit/connection (AC: #2, #3, #4)
- [x] Verificare bootstrap condiviso e assenza di stub locali (AC: #3, #5)
- [ ] Aggiornare `docs/phpstan.md` e rieseguire gate (AC: #1, #5)
