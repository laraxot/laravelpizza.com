# PHPStan L10 Test Fixtures & Files Type Fixes

**Goal**: Fix 16 test-related PHPStan L10 errors in Lang module by adding proper type hints to fixtures and test files.

## Phase 1: Analysis & Partial Fixes (COMPLETED)

**Completed**:
- ✅ Analyzed PHPStan timeout root cause (full-tree analysis on Xot dependencies)
- ✅ Identified 3 primary error patterns in test code
- ✅ Fixed 2 test fixtures with app() type casting
- ✅ Created comprehensive analysis document
- ✅ Documented all files requiring fixes with line numbers

**Errors Identified** (16 + estimated errors):
1. **app() mixed type chains**: 40+ instances
   - Affects: AutoLabelAction, PublishTranslationAction, SaveTransAction, RecordMissingTranslationAction
   - Files: LangHundredPercentCoverageTest, LangFinalGapsTest, Models/* tests

2. **Array access without type narrowing**: 15+ instances
   - Affects: Direct [0]['key'] access without @var type hints
   - Files: LangHundredPercentCoverageTest, Models tests

3. **Missing test helper return types**: 3-5 instances
   - Affects: langHundredFakeUser(), langMixedCollection()
   - Files: LangHundredPercentCoverageTest

## Successfully Fixed Files

### AutoLabelStaticCaller.php (✅ Type-safe)
```php
// Before: return app(AutoLabelAction::class)->execute(...)
// After: Cast app() to AutoLabelAction, then call execute()
/** @var AutoLabelAction $action */
$action = app(AutoLabelAction::class);
return $action->execute($component, $type);
```

### AutoLabelExecuteNestedCaller.php (✅ Type-safe)
```php
// Same pattern applied
/** @var AutoLabelAction $action */
$action = app(AutoLabelAction::class);
return $action->execute($component, $type);
```
