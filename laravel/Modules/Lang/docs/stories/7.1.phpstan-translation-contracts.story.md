# Story 7.1-LANG: Contratti PHPStan traduzioni

## Story

Come maintainer Lang, voglio tipizzare azioni, componenti, modelli, seeder e test delle traduzioni, affinché Lang sia indipendente dalla story User.

## Acceptance Criteria

<!-- LOCKED. External dev tools must not edit Acceptance Criteria. -->

1. PHPStan su `Modules/Lang` termina con zero errori con config invariata.
2. AutoLabelAction, editor/select Filament, Translation/Post/TranslationFile e seeder hanno tipi concreti coerenti con i file lingua.
3. ReadTranslationFileActionTest e BaseModelLangTest verificano contratti reali senza helper fantasma o tautologie.
4. Nessun ignore, baseline, config, Service nuovo o `mixed` evitabile è introdotto.
5. `docs/phpstan.md` diventa il punto corrente DRY e collega la story combinata 5.1 come superseded per Lang.

## Tasks / Subtasks

- [x] Catturare baseline separata da User e raggruppare per boundary (AC: #1, #2)
- [x] Correggere applicazione, seeder e test alla fonte (AC: #2, #3)
- [x] Cercare trait/Action esistenti prima di nuovi file (AC: #4)
- [ ] Consolidare `docs/phpstan.md` e rieseguire PHPStan (AC: #1, #5)

## Dev Agent Record

### Implementation

- Integrate senza revert le correzioni applicative/test già presenti nello scope:
  l'intero boundary owned risultava PHPStan verde all'handoff.
- Verificata la presenza delle Action e dei trait esistenti; nessun nuovo file
  applicativo e nessun Service sono stati creati.
- Consolidato `docs/phpstan.md` come guida corrente Lang e marcata la story 5.1
  combinata come superseded esclusivamente per l'ownership Lang.

### Verification (2026-08-24)

- Baseline module-wide Lang: 103 errori, tutti in `tests/TestCase.php` e test
  coverage fuori owned scope.
- PHPStan scoped su Action, albero Filament, modelli, seeder e due test owned:
  PASS, zero errori.
- `php -l` su tutti i file PHP owned: PASS.
- Pest mirato `ReadTranslationFileActionTest` + `BaseModelLangTest`: 19 PASS,
  42 asserzioni; coperti errori reali, nesting, scalari e ordine delle chiavi.
- PHPMD: BLOCKED prima dell'analisi per incompatibilità della firma
  `PdependExtension::load()` con Symfony DependencyInjection.
- PHP Insights: binario non disponibile in `vendor/bin`.
- `graphify update .`: tentato con timeout controllato; il lock condiviso non è
  stato acquisito entro 20 secondi e non è stato rimosso o alterato.
