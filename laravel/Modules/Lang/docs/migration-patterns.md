# Pattern delle migrazioni

Questo documento duplicava pattern e regole di naming, alcuni dei quali erano
incoerenti con l'implementazione attuale. La guida owner è ora
[migrations.md](./migrations.md); la regola piattaforma è
[Naming delle migrazioni dal modello](../../Xot/docs/wiki/rules/migration-filename-from-model-name.md).

Per evitare due fonti di verità, i pattern di creazione e aggiornamento schema
sono mantenuti solo nelle guide canoniche collegate sopra.
