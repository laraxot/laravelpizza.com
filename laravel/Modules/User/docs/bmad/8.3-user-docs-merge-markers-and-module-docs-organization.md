# 8.3: User: cleanup merge markers e riordino docs/module

## Scopo (perché)
I file `.md` di `Modules/User/docs/` contengono ancora merge markers (`<<<<<<<`, `=======`, `>>>>>>>`): residui di merge non risolti che inquinano la ricerca (QMD) e falsano i documenti. Serve un cleanup sistematico e una convenzione stabile: nome file kebab-case **senza date/timestamp**, YAML frontmatter valido con chiave `qmd`, docs sempre **nel modulo** (mai solo in `docs/` root).

## Piano
- [ ] Censimento file con marker (tool: `grep -rl` su `Modules/User/docs`): SSoT conteggio in `docs/phpstan-docs-cleanup.md`.
- [ ] Rimozione marker conservando il contenuto utile (i due lati della merge, non scartare informazione).
- [ ] Verifica frontmatter: chiavi `id/slug/title/description/qmd/status` presenti.
- [ ] Rinomina `.md` con date nel nome solo quando i link di ingresso sono aggiornabili (debito aperto: `quality-improvements-2025-01-06.md` nel modulo Lang).
- [ ] `qmd update` a fine intervento.

## Vincoli
Nessun `migrate:fresh`/test su host `10.100.200.15`; editing solo docs (nessun effetto runtime).
