# Story 8.1: PHPStan L10 User Module: Config offsetAccess Resolution

> **Aggiornamento 2026-10-06 (secondo giro)**: la soluzione sotto basata su `@var` inline NON regge con la config corrente
> (`treatPhpDocTypesAsCertain: false`): PHPStan segnala di nuovo `mixed given`. La migrazione ora restringe i tipi a runtime
> (`config()->boolean()/array()`, helper `configString()`): vedi
> [phpstan-cleanup-user.dev](./phpstan-cleanup-user.dev.md). I nomi tabella restano sempre quelli di `config/permission.php`.

**Date**: 2026-10-06  
**Owner**: User module  
**Status**: RESOLVED  
**Goal**: Eliminate 77 offsetAccess.nonOffsetAccessible errors in User module migration

## Context

The User module's migration file (`2026_10_05_174817_create_permission_tables.php`) had 77 PHPStan L10 errors, all stemming from:
- `config()` helper returning `mixed` type
- Offset access on `mixed` without type narrowing: `config('...')['key']` 

Root cause: Spatie permission config values accessed via offset without static type declarations.

## Solution (Ponytail Minimal)

**Approach**: Type-narrow at assignment, not at call site.

1. **Extract config arrays with array cast**  
   ```php
   $tableNames = (array) config('permission.table_names');
   $columnNames = (array) config('permission.column_names');
   ```

2. **Extract specific config keys into typed local variables**  
   ```php
   /** @var string $permissionsTable */
   $permissionsTable = $tableNames['permissions'] ?? 'permissions';
   ```

3. **Type-narrow nullable values at usage site**  
   ```php
   if ($teams) {
       /** @var string $teamKey */
       $teamKey = $teamForeignKey;
       $table->unsignedBigInteger($teamKey);
   }
   ```

4. **Handle cache config with PHPDoc**  
   ```php
   /** @var string|null $cacheStore */
   $cacheStore = config('permission.cache.store');
   ```

## Files Changed

- `laravel/Modules/User/database/migrations/2026_10_05_174817_create_permission_tables.php`  
  - Added array casts for config arrays
  - Extracted 9 config keys as type-hinted local variables
  - Type-narrowed `$teamForeignKey` within conditional blocks
  - Typed cache config values
