## Story

Come **maintainer delle traduzioni del modulo**,
voglio **sapere se il commit sospetto ha colpito altri file lang oltre ai 4 gia' noti**,
cosi' che **non restino altri file svuotati non scoperti**.

## Acceptance Criteria

1. Identificare il commit sospetto che ha svuotato 4 file `lang/it` (issue #102). [Source: module-excellence-brainstorming.md#fork-4]
2. Verificare con `git log -S`/`git show` se altri file lang sono stati toccati dallo stesso commit o da commit adiacenti. [Source: module-excellence-prd.md#nfr-3]
3. Riportare l'ampiezza reale su #102, senza applicare fix in questa story. [Source: module-excellence-prd.md#nfr-1]

## Tasks / Subtasks
