## Story

Come **manutentore della documentazione del modulo**,
voglio **un unico file di stato PHPStan invece di 270 varianti corrotte**,
cosi' che **chi cerca lo stato PHPStan trovi un solo file affidabile**.

## Acceptance Criteria

1. Elencare tutti i file `docs/*phpstan*.md` (270 al momento della ricerca) con path, byte size, mtime. [Source: module-excellence-brainstorming.md#fork-1]
2. Identificare i file corrotti dal pattern di rename bacato (sottostringhe `-fix`/`-d` rimosse dal titolo, es. `phpstanes.md`, `phpstanebate.md`). [Source: module-excellence-brainstorming.md#fork-1]
3. Creare `docs/phpstan-status.md` con lo stato reale corrente (0 errori livello max, verificato `./vendor/bin/phpstan analyse Modules/User --memory-limit=-1`). [Source: module-excellence-architecture.md#1]
4. Elencare i file corrotti come candidati a cancellazione in un file `docs/phpstan-cleanup-candidates.md`: la cancellazione stessa resta una story futura, non eseguita qui. [Source: module-excellence-prd.md#nfr-1]

## Tasks / Subtasks

- [ ] Script di solo-lettura che elenca tutti i file *phpstan*.md con metadata (AC: #1)
- [ ] Classificare originali vs corrotti per pattern filename (AC: #2)
- [ ] Scrivere docs/phpstan-status.md come SSoT (AC: #3)
- [ ] Scrivere la lista dei candidati a cancellazione, senza cancellare (AC: #4)
