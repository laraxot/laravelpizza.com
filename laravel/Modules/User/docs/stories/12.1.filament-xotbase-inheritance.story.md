# 12.1: BaseEditUser e UserColumn conformi a XotBase

**Story ID:** 12.1  
**Epic:** 12: Audit UI/Filament modulo User  
**Slug:** filament-xotbase-inheritance  
**Status:** backlog

## Story

Come **sviluppatore/modulo User**,
voglio **che le classi Filament di `app/Filament` estendano le basi Xot come da regola progetto**,
così che **i fix/patch Xot vengano raccolti ovunque, senza eccezioni ad hoc**.

## Evidenza

- `app/Filament/Resources/UserResource/Pages/BaseEditUser.php:22` → `abstract class BaseEditUser extends EditRecord` (unico Base* non Xot).
- `app/Filament/Tables/Columns/UserColumn.php:25` → `class UserColumn extends GroupColumn`.
- I 3 fratelli sono già conformi: `BaseCreateUser extends XotBaseCreateRecord`, `BaseListUsers extends XotBaseListRecords`, `BaseViewUser extends XotBaseViewRecord`.
- Base disponibili nel modulo Xot: `app/Filament/Resources/Pages/XotBaseEditRecord.php`, `app/Filament/Tables/Columns/XotBaseColumnGroup.php`.

## Acceptance Criteria

1. `BaseEditUser extends XotBaseEditRecord`; nessuna firma dei metodi ereditati alterata (getHeaderActions, mutateFormData… ecc. restano come oggi).
2. `UserColumn extends XotBaseColumnGroup`; `getColumns()`/colonne restituite invariate.
3. `rg "extends EditRecord|extends GroupColumn" Modules/User/app/Filament` → zero hit.
4. Nessun cambio a `CreateUser/EditUser/ListUsers/ViewUser` concreti (solo le Base toccate).

## Tasks / Subtasks

- [ ] Cambiare la classe base di `BaseEditUser` (AC: #1, #3)
- [ ] Cambiare la classe base di `UserColumn` (AC: #2, #3)
- [ ] Verifica reale: `user` crea/modifica/lista/visualizza OK nei test esistenti (`tests/Feature/Filament/CreateUserTest`, `ListUsersTest`) (AC: #4)
