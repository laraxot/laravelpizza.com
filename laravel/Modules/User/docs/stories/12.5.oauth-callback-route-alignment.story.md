# 12.5: OAuth Callback Route Alignment

**Story ID:** 12.5  
**Epic:** 12: Audit UI/Filament modulo User  
**Slug:** oauth-callback-route-alignment  
**Status:** done

## Story

Come **utente con OAuth Google configurato**,
voglio **il callback Google che torni a `/it/auth/login/google/callback`** (non `/sso/google/callback`),
così che **il flusso OAuth sia coerente con il percorso login e non abbia errori di redirect mismatch**.

## Evidenza (sha 2026-10-18)

| File | Prima | Dopo |
|------|-------|------|
| `Modules/User/routes/socialite.php` | `/sso/{provider}/callback` | `/it/auth/login/{provider}/callback` |
| `.env` | `GOOGLE_REDIRECT_URI=http://192.168.1.40:8000/auth/google/callback` | `GOOGLE_REDIRECT_URI=https://fixcity.eu/it/auth/login/google/callback` |
| `Themes/Sixteen/resources/views/pages/auth/[provider]/index.blade.php` |: | Creato (Folio page) |
| `Modules/User/app/Filament/Widgets/Auth/LoginWidget.php` | `route('socialite.oauth.redirect', ...)` | `route('oauth.redirect', ...)` |

## Root Cause Analysis (BMAD)

- **B (Benchmark)**: Filament-Socialite default route `/sso/{provider}/callback` non coincideva con il percorso login `/it/auth/login/{provider}`.
- **M (Model)**: OAuth flow richiede che `GOOGLE_REDIRECT_URI` (configurato in Google Cloud Console) corrisponda esattamente alla route callback.
- **A (Audit)**: Due problemi:
  1. Route callback era `/sso/{provider}/callback` (non `/it/auth/login/{provider}/callback`)
  2. `.env` GOOGLE_REDIRECT_URI era `http://192.168.1.40:8000/auth/google/callback` (URL locale errata, non corrispondente)
- **D (Deliver)**: Allineato tutto il flusso OAuth al percorso login `/it/auth/login/{provider}/callback`.

## Acceptance Criteria

1. ✅ Route callback: `/it/auth/login/{provider}/callback` (con prefisso locale `/it` da LaravelLocalization)
2. ✅ `.env`: `GOOGLE_REDIRECT_URI=https://fixcity.eu/it/auth/login/google/callback`
3. ✅ Route name: `oauth.redirect` (senza ridondante prefix `socialite.`)
4. ✅ `LoginWidget.php`: Google button usa `route('oauth.redirect', ['provider' => 'google'])`
5. ✅ `pages/auth/[provider]/index.blade.php`: Pagina Folio per provider con CMP-HERO + `.card-teaser`
6. ✅ Stack: Tailwind + Alpine + Lit + DaisyUI + Flowbite (NO Bootstrap Italia)
7. ✅ Nessun `web.php`/`api.php`/controller modificato (solo `routes/socialite.php` + widget Filament)

## Prevent Future Errors (BMAD + Second Brain)

Per evitare errori di redirect mismatch in futuro:
1. **Sempre** configurare `GOOGLE_REDIRECT_URI` (o altro provider) per corrispondere esattamente alla route callback
2. **Verificare** che la route callback abbia lo stesso prefisso della route redirect (`/auth/login/{provider}/callback` per entrambi)
3. **Non usare** prefissi diversi (`/sso/` vs `/auth/login/`): creano mismatch OAuth
4. **Usare** `route('oauth.redirect', ['provider' => 'google'])` invece di URL hardcoded per coerenza
5. **Testare** il flusso completo: login → Google → callback → redirect al dashboard
