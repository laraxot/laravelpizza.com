# 14.9: Marcatori di conflitto nei PHP di lingua e test del modulo User

> Numerazione: prosegue la sequenza dopo 14.8. La story e' igiene del repository, non un criterio di dominio
> dell'epic 14. Le story esistenti non sono toccate; i `.md` di User sono un altro lavoro
> (`docs-merge-conflict-markers-cleanup.story.md`).

## Obiettivo

`phpstan analyse Modules` non parte finche' i file PHP committati contengono `<<<<<<<` / `=======` / `>>>>>>>`.
Il lavoro non e' scegliere un lato a caso: per ogni file si e' capito a cosa serve e si e' lasciato un file che lo fa,
con i miglioramenti reali di entrambi i lati. Pagina di riferimento: [sync-marker-repair-php-lang-tests.md](../sync-marker-repair-php-lang-tests.md).

## Perimetro

File `*.php` e `*.blade.php` di `laravel/Modules/User` con marcatori: 6 file di lingua (4 con marcatori residui, 2 gia'
puliti ma verificati) e 22+ test. Fuori perimetro: `.md` di User, altri moduli, PHPStan (lo lancia l'orchestratore a
fine lavoro).

## Verifica (prove, non "fatto")

- `git grep -lIE '^(<<<<<<<|>>>>>>>) ' -- 'laravel/Modules/User/*.php' 'laravel/Modules/User/*.blade.php'`: nessun file.
- `php -l` su tutti i 40 file PHP toccati: nessun errore.
- `./vendor/bin/pint --test` aveva segnalato 7 file con stile non conforme (parentesi su `new`, spazi sugli operatori
  unari, import non ordinati); sistemati con `./vendor/bin/pint` sugli stessi 7 file.
- Backup prima delle scritture: `backup-laneD.tgz` (865 file, conteggio verificato con `tar -tzf | wc -l`).
