## Story

Come **chi cerca un bugfix storico nel modulo**,
voglio **una sola cartella convenzionale per gli archivi**,
cosi' che **non debba controllare 6+ posti diversi**.

## Acceptance Criteria

1. Censire tutti i file nelle cartelle `archive/`, `_archive/`, `wiki-archive/`, `fixes/`, `bug-fixes/`, `bugfix/`, `bugs/`, `bug-tracking/` (1090+ file). [Source: module-excellence-brainstorming.md#fork-1]
2. Dichiarare quale cartella e' la SSoT e quali sono alias/candidate a merge. [Source: module-excellence-prd.md#fr-123]
3. Nessun file va spostato o cancellato in questa story: solo la dichiarazione di convenzione. [Source: module-excellence-prd.md#nfr-1]

## Tasks / Subtasks

- [ ] Censire i file per cartella con conteggio (AC: #1)
- [ ] Scrivere la convenzione dichiarata in un documento dedicato (AC: #2, #3)
