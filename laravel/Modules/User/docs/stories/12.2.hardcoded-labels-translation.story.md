# 12.2: Label e testi hardcoded → lang `user::`

**Story ID:** 12.2  
**Epic:** 12: Audit UI/Filament modulo User  
**Slug:** hardcoded-labels-translation  
**Status:** backlog

## Story

Come **utente/amministratore multiplo**,
voglio **vedere la UI in italiano coerente anche su resource OAuth/team/tenant**,
così che **nessuna stringa inglese o hardcoded compaia nel panel**.

## Evidenza (23 label + testi, grep `->label(` del 2026-09-22)

- `app/Filament/Clusters/Passport/Resources/OauthClientResource/RelationManagers/TokensRelationManager.php`: Revocati, Scaduti, Validi, Visualizza, Revoca.
- `app/Filament/Clusters/Passport/Resources/OauthPersonalAccessClientResource.php`: ID, Client, Created At, Updated At (+ Client).
- `OauthPersonalAccessClientForm` (cluster **e** radice): 'Client' + helperText 'Associated OAuth client'.
- `app/Filament/Resources/TeamUserResource/Schemas/TeamUserForm.php`: 'Team' + helperText 'Role of the user in the team'.
- `app/Filament/Resources/TenantUserResource/Schemas/TenantUserForm.php`: 3 label.
- `app/Filament/Resources/UserResource/RelationManagers/ClientsRelationManager.php`: 5 label + tooltip 'Il secret viene cifrato e non è più recuperabile…'.
- `app/Filament/Forms/Components/SingleRoleSelect.php`: placeholder 'Select a role'.
- `app/Filament/Pages/SocialiteProviderSettingsPage.php`: placeholder inglesi (es. 'xxx.apps.googleusercontent.com').

## Acceptance Criteria

1. Grep `->label('` / `->label("` in `app/Filament` → zero hit.
2. Grep `helperText|placeholder|tooltip` con stringa letterale inglese/decade-to-console nei file elencati → zero hit.
3. Ogni stringa esiste in `lang/it/` (o tema esteso via `user::`), additivo senza rifattorizzare chiavi già usate altrove.
4. Testi esistenti già tradotti (es. lang `oauth_client.php`, `team_user.php`, `tenant_user.php`) riusati se la chiave coincide.

## Tasks / Subtasks

- [ ] Inventario chiavi mancanti per file (AC: #1, #2)
- [ ] Aggiungere le chiavi ai file `lang/it/*.php` (AC: #3)
- [ ] Sostituire le stringhe in `app/Filament/**` (AC: #1, #2)
- [ ] Verifica `php artisan lang:lint`/grep finale (AC: #4)

## Testing

- Grep zero su label/helperText/placeholder/tooltip hardcoded.
- PHPStan `Modules/User` level max (traduzioni typed come oggi).
