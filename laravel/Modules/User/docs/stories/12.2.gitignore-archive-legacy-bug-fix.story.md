## Story

Come **sviluppatore che scrive nuovi file in docs/archive/ o docs/legacy/**,
voglio **che git non li ignori silenziosamente**,
cosi' che **il lavoro futuro non scompaia senza errore**.

## Acceptance Criteria

1. `docs/.gitignore` righe 8-9 non devono piu' avere pattern bare `archive`/`legacy` senza prefisso. [Source: module-excellence-brainstorming.md#fork-1]
2. I pattern vanno riscritti come `docs/archive/` e `docs/legacy/` (o equivalente ancorato). [Source: module-excellence-prd.md#fr-122]
3. Il blocco duplicato nel `.gitignore` di root modulo (500 righe, stesso blocco ripetuto due volte) va deduplicato. [Source: module-excellence-brainstorming.md#fork-1]
4. Verifica: `git check-ignore -v docs/archive/<nuovo-file-di-prova>.md` non deve piu' matchare dopo il fix. [Source: module-excellence-prd.md#nfr-3]

## Tasks / Subtasks

- [ ] Riscrivere i pattern in docs/.gitignore (AC: #1, #2)
- [ ] Deduplicare il blocco nel .gitignore di root modulo (AC: #3)
- [ ] Verificare con git check-ignore -v su un file di prova (AC: #4)
