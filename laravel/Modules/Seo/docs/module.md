# Seo Module — Doctrine

## Scope (Scopo)

Seo gestisce metadati per l'ottimizzazione motori di ricerca: tag Open Graph, Twitter Card, sitemap, feed. Ottimizza silenziosamente ogni contenuto.

## Religion (Religione)

**"La visibilità è silenziosa, l'ottimizzazione è invisibile."** SEO è per le macchine, non per gli umani: ogni entità ottimizzata automaticamente, senza che l'autore debba conoscere SEO.

## Philosophy (Filosofia)

- **Adapter pattern**: Facade dietro complessità
- **Convention-over-configuration**: defaults ragionevoli
- **Platform-specific**: Google, Facebook, Twitter
- **Dynamic generation**: metatag generati dallo stato
- **Auto sitemap**: sitemap generata automaticamente

## Policy (Politica)

- Ogni entità ottimizzabile implementa contratto
- Metatag generati dinamicamente
- Multiple piattaforme supportate
- Sitemap generata automaticamente
- Configurazioni con defaults

## Why (Perché)

SEO implica formati specifici, generazione sitemap, integrazione con servizi. Un modulo dedicato garantisce che ogni contenuto sia SEO-ready automaticamente.

## Zen

*"Visibilità silenziosa. Ogni contenuto ottimizzato, ogni pagina indicizzata."*

## Gap

- Test per formati limitati
- Policies assenti
- Best practices non documentate
- Logiche adapter poco testate
- Meccanismi validazione mancanti

## Add

- Policies
- Test per formati diversi
- Servizi suggerimento miglioramenti
- Reporting SEO performance
- Caching per metatag frequentati

## Split/Merge

**Mantenere come-is.** Il focus su ottimizzazione motori di ricerca è un servizio di supporto distinto. Separato dai moduli di contenuto che serve.

## Future Enhancements

1. **SEO scoring AI**: punteggio automatico per ogni pagina
2. **Keyword optimization**: suggerimenti keyword
3. **Schema.org automation**: markup strutturato automatico
4. **Core Web Vitals monitoring**: monitoraggio performance
5. **Competitor analysis**: analisi SEO competitor
6. **Automated reporting**: report SEO periodici
