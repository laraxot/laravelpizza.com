# Archive Convention Decision (Story 18-2)

## Context

Epic 18 ("Sincronizzazione Drift + Dedup Docs") requires consolidating and
deduplicating documentation spread across 6+ modules (Ui, Job, AI, Cms, Xot,
Lang, etc.). A critical blocker: **what is the canonical convention for archived
docs?**

Currently, two conventions exist in parallel:

1. **`docs/_archive/`** — underscore-prefixed, signals "meta/internal" by convention
   (used in other contexts: `_bmad/`, `_components.json`, etc.).
2. **`docs/archive/`** — plain name, possibly `.gitignore`d or not depending on
   intent.

**This story blocks story 18-3** ("Implement Dedup + Archive Strategy"), which
needs an agreed convention before proceeding.

## Acceptance Criteria

### AC-1: Canonical Convention Decision

Decide on **one single convention** for archived docs across the monorepo:

- **Option A**: Use `docs/_archive/` (underscore prefix) as the canonical path.
  - Pros: Signals "internal/meta" by convention; aligns with existing `_bmad/`,
    `_components.json` patterns; sorts first in directory listings.
  - Cons: Underscore prefix slightly less discoverable without explicit knowledge.
  
- **Option B**: Use `docs/archive/` (plain name) as the canonical path.
  - Pros: Immediately discoverable; no special syntax; clear intent.
  - Cons: No visual signal that it is "meta"; potential confusion with regular
    doc folders; requires explicit `.gitignore` rule to prevent commits.

- **Option C**: Hybrid (one for per-module dedup, another for cross-module/root
  archive).
  - Requires detailed decision on which use case maps to which path.

**Decision outcome**: `AC-1-DECISION` (to be filled in during execution).

### AC-2: Communicate Decision to Team

Once AC-1 is decided:

1. **Document the decision** in `docs/decisions/` (see AC-3 for path/format).
2. **Announce via `docs/chat/`** (pre-announcement before story 18-3 begins).
3. **Unblock story 18-3** by providing the agreed convention.

This prevents story 18-3 from starting with ambiguous assumptions.
