# Hub risorse (ownership Cms)

## Pattern AFC

Su [AFC risorse](https://www.afcformazione.it/risorse-strumenti-comunicazione-aziendale/)
le risorse sono poche, ordinate per **bisogno** (diagnosi → applicazione →
approfondimento), non per formato file.

## Traduzione FixCity

Pagina Cms `risorse` (o `guide`) con:

1. Checklist cittadino / operatore
2. One-pager adozione Comune
3. Link a blog evergreen e a eventi futuri
4. FAQ privacy/segnalazione

Niente cento PDF. Contenuto in JSON tenant; Sixteen solo vestito.
