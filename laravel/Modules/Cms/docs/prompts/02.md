# Prompt 02 — Filament layout obbligatorio

## Contratto (Filament 5.x)

Fonte: [Configuring your layout](https://filamentphp.com/docs/5.x/introduction/installation#configuring-your-layout).

1. `resources/views/components/head.blade.php` → **obbligatorio** `@filamentStyles` (prima di `@vite` CSS tema)
2. `resources/views/components/foot.blade.php` → **obbligatorio** `@filamentScripts` (dopo notifications, prima di `@vite` JS)
3. Notifications: solo `@livewire('notifications')` — **mai** dentro `@auth`
