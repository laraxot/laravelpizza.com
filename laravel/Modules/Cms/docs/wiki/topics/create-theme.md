## Prerequisiti

3. Conoscenza base di Vite e Tailwind CSS
4. PHP 8.1+
5. Laravel v10.0+

## Passo 1: Struttura del Tema

Un tema è organizzato come un pacchetto Composer con la seguente struttura:

```
theme-name/
├── composer.json
├── package.json
├── vite.config.ts
├── tailwind.config.js
├── postcss.config.js
├── theme.json
├── index.html
├── config/
│   └── theme.php
