# Manuale utente Cms

Integra il [manuale actor-oriented](../manuale-uso-attori.md). CMS risolve slug, contenuti, blocchi e middleware delle pagine.

## Attori e uso

| Attore | Uso verificato |
|---|---|
| Visitatore/utente | Consulta pagine e blocchi pubblicati. |
| Gruppo/editor | Cura contenuti nelle risorse autorizzate. |
| Admin/super-admin | Gestisce pagine, menu, blocchi e configurazione CMS. |

Il tema non deve duplicare una pagina CMS con un alias Folio.
