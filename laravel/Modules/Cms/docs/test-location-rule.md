# Test Location Rule — Cms

- Tests: `laravel/Modules/Cms/tests/`.
- Module fixtures: `laravel/Modules/Cms/tests/Fixtures/`.
- `laravel/tests/` is reserved for application, cross-module and theme tests.
- Do not create `laravel/tests/Modules/Cms/` as a duplicate.
