# Bozze di GitHub Discussions

Le Discussions di GitHub si creano solo con l'API GraphQL, che dalle sessioni di Claude Code non è raggiungibile.
Per ogni lavoro Claude apre l'issue (API REST) e scrive qui il testo della Discussion, pronto da incollare in
https://github.com/laraxot/laravelpizza.com/discussions/new (categoria suggerita in testa al file).

Dopo averla pubblicata, aggiungere il link in fondo al file e segnare `pubblicata: sì`.
